# 森林新增敌人的招式（2026-11-05）

来源：参考游戏 0.8.83 招式数据的对应 key；中文名、属性与核心行为已核对。未将主系列数值照搬，也未核对动画 GIF。

| key | 核心身份 | 本项目模拟与视觉 |
| --- | --- | --- |
| `harden` 变硬 | 强化自身防御；甲壳变硬 | 0.6s 起手，3s 内直接命中伤害 ×0.55，不额外减燃烧 tick；身体细环，无攻击危险区 |
| `poison-sting` 毒针 | 细小毒针，毒属性，可能中毒 | 0.65s 固定方向细线 → 半径0.14、速度6的针；命中0.65×接触伤害并给玩家2s中毒；紫色针尖和暗紫边 |
| `ember` 火花 | 小型火焰弹 | 0.7s 固定方向细线 → 半径0.23、速度5的火花；命中0.9×接触伤害；橙色小火焰，敌方暗边 |
| `flame-charge` 蓄能焰袭 | 身体包裹火焰向前冲 | 0.8s 标线 → 9u/s冲0.55s → 收招0.9s；卡蒂狗身上小火焰；不加永久速度 |
| `discharge` 放电 | 向周围释放电流 | 1s 预警圆 → 半径2.8单次0.9×伤害 → 0.25s消退；黄电与暗红危险轮廓，无玩家麻痹 |
| `self-destruct` 自爆 | 自身失去战斗能力的范围爆炸 | 1.5s 预警圆 → 半径3.8单次1.6×伤害，移除施法者且无击倒/战利品/捕获奖励 → 0.3s消退 |

预警等级写在各招式模块 `telegraph` 的 `tell`（`src/run/sim/skills/`）：普通技能蓝，只有自爆为新增红色危险预警；精英仍统一红。毒针只给玩家施毒；敌人没有中毒处理，不声称同伴毒针附毒。

所有攻击在蓄力时被击倒或睡眠均可取消；径向范围与发射线路随蓄力施法者的击退位移移动，方向锁定。射击的发射位置和方向直接使用预警数据。火焰冲刺沿用地面可走直线判定。径向攻击和同伴脉冲逐目标检查岩石/地形遮挡，爆炸之后的消退效果不再命中。

视觉沿用现有 sprite / danger decal / ally decal 池，新增 GPU 材质和 draw-call 种类为0；没有新模型动画绑定。减少动态时保留固定预警、弹体和单次命中轮廓，不增加抖动或重随机闪电。实际群怪性能与渲染验证记录见 `docs/state-machines/simulation.md`。
