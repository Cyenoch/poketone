# 自爆 Self-Destruct (`self-destruct`) — normal · nova

- 52poke: <https://wiki.52poke.com/wiki/自爆> · Bulbapedia: <https://bulbapedia.bulbagarden.net/wiki/Self-Destruct_(move)>
- 本地参考：`derived/moves.json` 的 `self-destruct`，一般属性 nova。未核对动画 GIF。
- 保留身份：以自身为中心的单次爆炸、施法者退场、充足躲避时间。
- 本作：顽皮雷弹 1.5 秒红色危险预警，半径 3.8、1.6 倍接触伤害；之后 0.3 秒收拢消退，不再命中。检查每名玩家视线与高差。
- 睡眠 / 击倒可中断；自身退场不计击倒、不掉落、不捕获。同伴改用可重复范围脉冲。完整设计与验证见 [敌人扩展](enemy-expansion.md)。
