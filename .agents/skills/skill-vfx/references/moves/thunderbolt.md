# 十万伏特 Thunderbolt (`thunderbolt`) — electric · chain · mid

- 52poke: <https://wiki.52poke.com/wiki/十万伏特> · Bulbapedia: <https://bulbapedia.bulbagarden.net/wiki/Thunderbolt_(move)>
- Description: 向对手发出强力电击进行攻击。有时会让对手陷入麻痹状态。 *[52poke]*

Signature traits
- Pikachu's iconic **zig-zag yellow bolts** with a white-hot core. *[familiar — check the GIF]*
- Cheeks spark before the release. *[familiar]*

Reference game: each link = a thick volt lightning plus a thin white core lightning; a bolt
sprite on the struck target.

Sim: instant chain from the player through count + 1 = 3 enemies within 4.5 m hops; event `chain`
with the points.

Keep: zig-zag, white core, per-target spark. Avoid: long linger (≤ 0.3 s), fat glow halos.
