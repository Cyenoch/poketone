# 毒针 Poison Sting (`poison-sting`) — poison · bolt

- 52poke: <https://wiki.52poke.com/wiki/毒针> · Bulbapedia: <https://bulbapedia.bulbagarden.net/wiki/Poison_Sting_(move)>
- 本地参考：`derived/moves.json` 的 `poison-sting`，毒属性 bolt。未核对动画 GIF。
- 保留身份：细针、明确方向、小型紫色毒弹。避免宽激光或铺满屏幕的雾。
- 本作：尼多兰 / 尼多朗锁定朝向，0.65 秒细线预警后发射，半径 0.14、速度 6、寿命 1.6 秒；0.65 倍接触伤害与玩家中毒 2 秒。先撞到岩石 / 地形就消失。
- 预警从施法者出发，击退时随人移动；同伴不对敌人附毒。完整设计与验证见 [敌人扩展](enemy-expansion.md)。
