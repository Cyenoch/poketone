# 苍龙风暴 (`dragon-tempest`) — dragon · tempest · big

本项目原创融合招式（龙卷风 + 龙之波动），无同名原作动画。参考父招式的本地说明以及 OpenSpec 交接表。

## 设计

- 意图 / 签名：风暴在身周聚起，同时喷出多道龙脉；**数量 = 龙脉束数**，每次 +数量 都必须多出一束看得见的光束。旧版（bloom：单束 + 侧飞鳞片）被玩家评为「太搞笑」且升级数量看不出变化，已弃用。
- 模拟几何与时序（`sim/archetypes/tempest.ts`，参数 `TEMPEST`）：束数 ⌊count⌋（基础 2，上限 12）；每束起点在施放处身周 rim 1.1×scale 的风暴缘上，宽 .7（实例 radius .35），长 ≤8 被地形裁切，不随身移动；第 i 束 delay .45+i×.04，持续 .9×dur，每 .15 s tick；到期在束端出 r1.4×scale 龙星终爆。各束优先指向彼此相隔 ≥.38 rad 的不同敌人；不够时从风暴缘两侧（单侧 ≤1.5 rad）汇向主目标，所以单个守卫会被多束同时穿过。
- 阶段：聚气（每束起点一圈收紧的青白风弧 + 渐亮光晕 + 沿束展开的细引导线）→ 喷发（起点金星闪 + 小环 + 3 片鳞）→ 持续（青黛 beam 体 + 金/青白两股向束头逐渐张开的风旋 + 束头青光）→ 最后 140 ms 收窄 → 终爆（复用 `dragonBurst`）。
- 保留与避让：每束保持细（风旋在实例宽度内）；不用暗色三角或 shard；鳞片少量（每束 6/s）。多束合起来才是"风暴"，单束不再加大。
- 分层：既有 beam volume（style 2）、strip 贴花、ribbon solid 风旋、glow 精灵；无新材质或绘制批次。12 束时 ribbon 约 1000 点、beam 体 12 个（容量 24）。
- 升级：count 增加束数（可见）；area 加宽束与风暴缘、放大终爆；dur 延长持续。
- 危险可读：不使用 danger 层、虚线、红环或饱和紫填充；引导线是细青线而非敌方虚线车道。
- 验证与评分：按 `template-and-rubric.md` 检查；日期截图与实际验收记录仅放临时证据目录，不在本参考笔记冒充通过。
