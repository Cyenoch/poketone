# 后续角色沿用方式

## 当前：trainer-cel-summer-v2

当前人物设定以 [README.md](README.md) 为准，四人全部为 **18 岁成年人**，后续原创角色沿用白皙肤色与亚洲审美。前三人设定记录见 [summer-v2-generation.json](summer-v2-generation.json)，夏晴见 [xiaqing/generation.json](xiaqing/generation.json)，发布立绘见 [runtime-summer-v2-generation.json](runtime-summer-v2-generation.json)。第一版记录仅保留历史来源。

- **固定参考**：`chengxi/turnaround-summer-v2.png`。澄汐重设时仅借第一版的线条、赛璐璐质感与设定图布局；夜苇、朔野与夏晴直接使用夏装澄汐作为画风参考。夏晴在自己的第一张夏装稿上调整领口、肩带、腰腹与裤长，保留调整前来源。
- **脸与比例**：年轻的日式角色面容、自然清爽，约 6.5–7.5 头身。澄汐甜美灵动；夜苇通过眼神和修长姿态形成御姐感；朔野为清爽少年系帅哥。不用年龄纹、凹陷面颊、浓妆、胡须或厚重职业服装塑造气质。
- **服装**：无袖或短袖、短裙或膝上短裤、轻薄面料和低帮鞋。澄汐白色过膝长袜，夜苇薄透黑色连裤丝袜。不添厚披风、长马甲、围巾、长袖、长裤或冬靴。
- **画法**：深海蓝干净描线，外轮廓略粗、内线较细；二至三档大块赛璐璐明暗，左上柔光、简洁哑光材料。保持清楚的脸、发型和标志配饰。
- **布局**：1536×1024 暖白底；上部四个同尺度全身视图（正面、朝左的本人左侧、背面、前三分之四），下部三个表情、两个配饰特写和四色色板；不生成文字。头发与鞋底完整，左右按角色自身定义。
- **后续派生**：每次传入固定画风参考和本人的夏装设定图；完整记录实际提示词、参数、模型、任务 ID、参考及输出哈希。提示词文件去掉末尾换行即为提交原文。新输出另存，不覆盖第一版源图。
- **发布制作**：每人从自己的当前设定图生成一张 `runtime-summer-v2.png`，再由 `prepare.py` 清理透明遮罩与边缘残色，保存 `runtime-summer-v2-clean.png` 并派生全身、切入和头像。夏晴再派生两张纯色剪影。尺寸、裁剪、alpha 处理和哈希见发布 `provenance.json`；不能把旧版 `lobby-source.png`、`cutin-source.png` 当作新版身份参考。

## 历史：trainer-cel-v1

画风版本：**trainer-cel-v1**。提示词的完整原文与参数以 [generation.json](generation.json) 为准，人物中文设定见 [README.md](README.md)。

本批次实际模型为 `ash/gpt-image-2.5-sunburst`，三张最终图均为 1536×1024 PNG。固定参考图为 `chengxi/turnaround.png`，其 SHA-256 已记录，便于识别后续是否误用修改过的参考。工具未提供 seed；可复用的是提示词、参数与图像参考组合。

### 第一版视觉语言

- 暖白背景 `#F5F1E8`，深海军蓝 `#142F50` 描边；外轮廓略粗，内部结构线略细。
- 明亮卡通冒险游戏；成年人约 5.5–6 头身，手脚适当概括，避免极端幼态比例。
- 大色块、二至三档赛璐璐明暗，哑光材料，左上方柔和光线；不增加写实纹理或复杂反光。
- 轮廓优先：每人一个主形状、四个主要配色、两三件最有识别度的装备。细节集中在脸与主要装备。
- 横向 3:2。上部四个全身：正面、人物左侧面、背面、前方三分之四；下部三个表情、两件装备细节、四色色板。
- 四视图同尺度、同地平线，手中不持物，手臂略离身体；前、侧、背面用正交感，不裁头脚。
- 配件左右按角色自身的左右定义，不按画面左右定义。
- 图面不生成文字，人物名与说明留在外部设定中。

### 第一版生成过程

1. 将 `chengxi/turnaround.png` 作为固定画风参考图通过 `reference_images` 实际上传给生成工具；仅在提示词里写文件名不能替代图像输入。继续使用这一张原始参考，避免一代代引用新图造成累积偏移。
2. 复制 `generation.json` 的一个角色条目，改写 `characterBrief`：名字、年龄、体型、面部、发型、轮廓、服装、左右装备、四个色值、三个表情、两处特写。保持其他风格与版式段落。
3. 按以下顺序，以两个换行连接为完整提示词：`layout` → 新的 `characterBrief` → `referenceInstruction` → `styleLock` → `projectStyle`。第一张澄汐没有图像参考，因此当次没有 `referenceInstruction`。
4. `referenceInstruction` 中保留「只匹配画风，不复制参考角色身份与服装」的含义。若新角色与澄汐体型相近，也仍须明确采用新角色自己的体型设计。
5. 沿用横向 `1536x1024` 请求、`quality: high`、单张一角色。模型由 Magpie 默认设置选择，实际返回模型写入生成记录；默认模型变化时要检查与原始参考的一致性，不能只凭相同提示词认为画风已锁定。
6. 保存完整提示词组成、参考路径、请求参数、实际返回模型与尺寸、生成任务 ID、原始输出。不要覆盖最初三张源图。新版本使用新的文件名与独立记录。

### 设定图检查

- 四个视角是否齐全，轮廓和服装是否可用于后续建模理解。
- 前后是否为同一人，头身比、发型、鞋型、袖长是否一致。
- 单侧配件是否意外换边、复制或消失；背包、腰带等是否前后可解释。
- 是否保持同样的描边、平涂明暗、背景、细节密度与表情语言。
- 如果进入建模阶段，应以文字设定锁定左右归属，并补齐尚未明确的结构；概念图不能代替网格、绑定和动画验收。

这些约束和参考图用于提高一致性；图像生成仍有随机性，复用时需要逐张目视检查。

### 第一版大厅全身立绘流程

- 用途：大厅左半的训练师全身立绘。画面从头发到鞋底完整，屏幕边缘可以裁腿，美术本身不止于腰部。姿势与 cut-in 一致：三分之四正面略朝画面右，本人右手举在肩旁拿红白球，另一只手向画面右前方张开。
- 提示词：`lobby-prompt.txt` 正文去掉末尾换行，加两个换行，再接该角色 `cutin-generation.json` 的 `characterBrief`。姿势用平实描述；含 lunge、legs apart、capture ball、weight on the front leg 的长提示词曾被安全系统拒绝。
- 参考图：本人 `turnaround.png` 与本人 `cutin-source.png` 一起实际上传。参数：`1024x1536`、`quality: high`、`background: transparent`、`n: 1`。
- 原图存为 `<id>/lobby-source.png`，记录写入 `<id>/lobby-generation.json`（完整提示词、参考图、参数、返回模型、任务 ID、SHA-256 与目检结论）。澄汐是这套模板的手写前身，其记录保留实际提示词原文。
- 第一版处理记录：主体 alpha 253–254 归一，alpha <8 杂点清零，外框裁切与 1400 长边无损 WebP。旧发布对应关系已保留在各角色的 `runtime-v1-provenance.json`；当前 `prepare.py` 使用上方的夏装制作流程，不再按这一历史流程导出。
