# 地图美术手册

本页维护六图的美术语言与制作参考；行为见 [world-progression](../openspec/specs/world-progression/spec.md) 与 [GPU呈现规范](../openspec/specs/gpu-presentation/spec.md)，技术方法见 [RENDERING](RENDERING.md)。实际颜色、尺寸、密度和节奏只在 [主题源码](../src/run/view/themes/) 维护，不再按旧截图的“现状乘倍数”修改。

## 共同方法

以各地图载入画的材料和气质作为参考，入口见 [runArt](../src/screens/runArt.ts)。把主材料、轮廓、明暗层次和地标做好，再按真实空缺加布景；不把载入插画的每个物体变成必须生成的资产。

危险区域、角色、敌人和拾取物优先于装饰。夜色、雾、液面高光及地表纹理不能吞没预警；视觉水岸、岩壁与地表危险要对齐真实边界。火山熔岩大面保持暗、亮缝提供热感，让红色攻击预警仍清楚。

火山不使用硫磺晶簇装饰；用户已反馈这种密集尖柱造型引起不适。

复用主题数据、材质和实例化。地表暖光可用材质内的光池、光斑、广告牌或少量氛围粒子实现；不为地图换气质新增全屏后处理。应用已有的分辨率合成render target不属于这一禁止范围，不把旧计划的“无新渲染目标”扩大成全局规则。

| 岩石沙漠 | 有风纹的浅沙、分层砂岩、亮色风化沿与碎石崖脚，干灌丛和图腾 | 热霾亮暖；日落仍分得清橙褐敌群；沙暴粒子集中外圈，地面保留中间调。                 |
| 风暴海岸 | 干湿沙过渡、圆润礁石、棕榈与热带灌木，潮线碎屑和灯塔       | 共用真实水岸采样；雨夜仍读成湿沙而非灰水泥，海侧开阔，波光不遮水面预警。           |

| 火山岛   | 玄武岩、灰烬、暗结壳熔岩、喷口与火口祭坛                   | 热感来自亮缝、边缘光和少量蒸汽，不用整片亮黄盖住战斗；安全堤道一眼可辨。           |
| 紫苑塔   | 石板、砌墙、柱础、墓碑、蜡烛簇和少量花瓣；关闭草地植被     | 墙比地面暗、比敌人低饱和；薄雾在预警下方，暗层保留脚边信息，塔顶保持月夜身份。     |

## 云影、风与草

云影和风使用同一世界方向，避免贴着镜头漂移或遮罩突然跳变。朝阳暖雾、倾斜光柱与林荫光斑为环境层，不抢角色轮廓；旋转镜头和切换区氛围时同时核对地面、预警与雾。

森林的层次和密度以当前主题及代表场景为起点；拾取物、低矮敌人和危险边界的实际可读性优先。风、云影和草复用现有主题与渲染实现。

## 验证与来源

调整前后固定构建、种子、区域、相机与采样条件；场景有变化时再补桌面/手机和不同氛围。帧时间、画面占比与主观评分只帮助判断，不能替代正式画面和用户判断，也不设数字外观门禁。

本页不维护活动任务或反复抄录通过数量；新调整在对应change指定实际验收范围。
