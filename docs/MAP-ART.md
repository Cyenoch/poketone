# 地图美术手册

本页维护六图的美术语言与制作参考；行为见 [world-progression](../openspec/specs/world-progression/spec.md) 与 [GPU呈现规范](../openspec/specs/gpu-presentation/spec.md)，技术方法见 [RENDERING](RENDERING.md)。实际颜色、尺寸、密度和节奏只在 [主题源码](../src/run/view/themes/) 维护，不再按旧截图的“现状乘倍数”修改。

## 共同方法

以各地图载入画的材料和气质作为参考，入口见 [runArt](../src/screens/runArt.ts)。把主材料、轮廓、明暗层次和地标做好，再按真实空缺加布景；不把载入插画的每个物体变成必须生成的资产。

危险区域、角色、敌人和拾取物优先于装饰。夜色、雾、液面高光及地表纹理不能吞没预警；视觉水岸、岩壁与地表危险要对齐真实边界。火山熔岩大面保持暗、亮缝提供热感，让红色攻击预警仍清楚。

火山不使用硫磺晶簇装饰；用户已反馈这种密集尖柱造型引起不适。

复用主题数据、材质和实例化。地表暖光可用材质内的光池、光斑、广告牌或少量氛围粒子实现；不为地图换气质新增全屏后处理。应用已有的分辨率合成render target不属于这一禁止范围，不把旧计划的“无新渲染目标”扩大成全局规则。

## 边界外

玩家在任何允许的相机位置都不应看到空底、地形边缘或背景色缺口；手机横屏的顶角看得最远，是检查重点。相机俯角约 50°，屏幕上缘仍在地平线下约 29°：平地只看到场地外十余米，远处只有“低于地面的东西”或“站在外面的高东西”能进入画面。所以边界外用两类东西填满，由主题 `backdrop` 字段描述（`environment/backdrop.ts`）：

- **外延地面**：从地形边缘接出一圈地裙，直接用地形材质，所以草、沙、雪、海底无缝延续；高度在几米内从边缘高度过渡到沿边平均值，再加该图的抬升和起伏（林丘、沙丘、雪原）；海侧按同一坡度沉入海底，海面平面同步外延并加深。
- **布景层**：用该图自己的道具模型实例化成林带、岩群、方山、冰崖、玄武岩脊、海蚀柱，按块剔除，不投影。判断位置看整个轮廓（模型外廓 × 缩放 × 拉伸），不看根点：整块轮廓都在地形方块之外，相机不会离开地形方块，所以永远不会挡住场地。放大的道具限制缩放，并按世界高度加一层岩层条纹（`strata`），读成分层的方山而不是光滑的大团块。
- **熔岩口与岩拱**：火山的熔岩口是不规则的扁平口子，外圈一道隆起的硬壳唇，热度从中心向唇边柔和衰减；沙漠的岩拱沿各边分槽摆放，拱洞朝向场地，粗糙六边截面加岩层条纹，一次合并绘制。两者可以站在场地与地形边缘之间的那圈边带上，桌面视角才看得到；它们离场地至少几米，边带上的岩拱高度不超过离场地的距离，始终低于镜头看场地边缘的视线。

紫苑塔没有外延地面：地板在围墙外沿截止，外面是向下的落差。从场地内只能看见“伸出去”的东西：塔墙每层微微外扩、层间有檐线，深扶壁一路落下，墙外还立着几座方塔，用飞扶壁连回扶壁，塔顶和尖顶都在地板附近或以下；方塔朝场地的一面开着一列列拱窗（暖灯、淡紫灯和暗窗）。石材是偏灰的淡紫，深度雾按高度把下层融进霾色，最底下是漂动的雾层（`environment/towerExterior.ts`）。只有站在近侧边缘、相机在墙外时才看得到塔墙正面；从场地内往远侧看，深度靠外立的方塔表现。地板以上的东西都在相机与场地连线之外，不会挡住场地；场地外不生长植物和散布装饰。

只用实例化、共享材质和已有雾，不加新的渲染通道。

## 云影、风与草

云影和风使用同一世界方向，避免贴着镜头漂移或遮罩突然跳变。朝阳暖雾、倾斜光柱与林荫光斑为环境层，不抢角色轮廓；旋转镜头和切换区氛围时同时核对地面、预警与雾。

森林的层次和密度以当前主题及代表场景为起点；拾取物、低矮敌人和危险边界的实际可读性优先。风、云影和草复用现有主题与渲染实现。

风中漂流物（沙纹、雪粉、灰烬与火星、落叶花瓣、塔内幽光与低雾）由主题 `drift` 描述，`environment/drift.ts` 每层一次实例化绘制：粒子绕视线落点循环，跟随共享风卷动，在屏幕中央淡出，不遮敌人、预警和拾取物。只读视图，不写回模拟。

动态氛围要在帧序列里看得出来，且都避开战斗中心：森林草地有顺风推进的阵风带（压弯并提亮叶尖）；沙漠最多同时两股尘卷风，只在镜头左右两侧生成、几秒后消散（`environment/dust-devil.ts`）；冰川雪面有随镜头移动闪烁的冰晶点，风雕雪纹只出现在被风刮过的斑块，避免整片平行条纹读成光带；火山熔岩上方有淡淡的热浪扭动；紫苑塔地板有高窗投下的拱形光斑和斜光，墙脚散落碎石（`environment/tower.ts`）。林荫光柱只来自树，没有树的地图不生成。

场地边界只在玩家靠近时显出近处一段：从地面升起、向上变淡的光幕，底边一道亮线，光幕里有缓慢上升的薄纱和闪动的光柱，玩家越贴近越亮；颜色由主题 `edge` 给出，按各图地面选对比色。不用警示条纹（`view/boundaryWall.ts`）。

## 地表、调色与散布

沙漠、海岸、冰川、火山和紫苑塔的步行地面、斑块与崖壁使用 Magpie 绘制的 512 无缝贴图（`public/art/ground-*.jpg`，细节/法线图同名 `-detail.png`，由 `scripts/paint-ground-maps.mjs` 从 `assets/textures/source/` 生成并写来源记录）。森林的草地与泥土、岩石沿用 `scripts/bake-ground-maps.mjs` 的程序贴图。

每个主题的 `grade` 是自己的调色（曝光、阴影/高光色偏、曲线），作为统一输出着色的 uniform 切换，不加后处理；森林保持默认值。冰川高光不偏黄，火山整体暗、高光暖，沙漠的石头仍读成石头而不是发光的橙色。

主题 `vegetation.pebbles` 在可走地面撒一层只读视图的小碎石（`environment/pebbles.ts`），不改变模拟里的道具数量。紫苑塔地板逐块变化色相、接缝积灰与苔藓、少量下陷石板与裂缝（`architecture.ts`）。塔内围墙、内墙和墙组与塔外立面同一石材：灰调淡紫的错缝条石，逐块色调变化、缺角接缝、潮痕与苔藓，顶部一道分段压顶石；墙、柱、墓碑和碎石都经 `duskStone` 降到与塔外相同的饱和度（`view/walls.ts`）。泉水按水面颜色重涂成浅到深的青绿并加波纹（`view/springWater.ts`）。遮挡物淡出用细颗粒的交错梯度噪声代替 4×4 Bayer 网格。

## 验证与来源

调整前后固定构建、种子、区域、相机与采样条件；场景有变化时再补桌面/手机和不同氛围。帧时间、画面占比与主观评分只帮助判断，不能替代正式画面和用户判断，也不设数字外观门禁。

本页不维护活动任务或反复抄录通过数量；新调整在对应change指定实际验收范围。
