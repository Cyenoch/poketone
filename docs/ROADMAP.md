# 未排期方向

这里只保留尚未立项的方向和重启条件，不列活动任务或完成进度。当前工作用 `bun run spec:list` 查询；产品红线见 [PRODUCT](../PRODUCT.md)。新增候选先确认具体问题与授权，再建立change。

| 方向                                   | 重启条件与边界                                                                                                                                                 |
| -------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 更多伙伴、招式、道具、状态及非招牌融合 | 先有获准的具体内容/首份配方，再扩展；参考游戏不是覆盖率目标，不按参考数量预建通用系统。                                                                        |
| 手动捕获/释放                          | 须先确定如何改变现有同伴规则，不从旧提案恢复成待执行步骤。                                                                                                     |
| 每图记录、成就、天气、变体和每日挑战   | 先确定玩法内容、记录/奖励与格式政策；当前地图氛围不等于战斗天气。                                                                                              |
| 无尽与守卫/特殊敌人骨骼动画            | 用户于2026-11-06决定后期再做。无尽重启前看 [确定性研究](research/DETERMINISM.md) 的实际数值边界；100级经验上限已经取消，不再作为待办。动画按具体资产需求启动。 |
| 潮汐、熔岩上涨、水龙卷/落石节拍        | 动态拓扑先闭合导航与快照恢复，见 [恢复原理](NAVIGATION.md#流场恢复)；不作为纯视觉增强偷偷改变玩法。                                                            |
| 塔可选机制                             | 钟声、可交互蜡烛、净化圈、捣蛋墓碑、专属塔顶模板需单独内容决定，未包含在当前首版。                                                                             |
| 换区失败后的重试/取消                  | 先确定失败UX及是否需要保留旧世界；当前载入屏障不承诺事务回滚。                                                                                                 |
| 地图后台生成/可中断装配                | 先测正式载入中的主线程瓶颈，再决定调度；保留同种子结果和最终可玩性检查。                                                                                       |
| 渲染与内存热点                         | 先测上传/提交、可见打包、纹理驻留或主线程开销；只有具体热点才试活动前缀、保守裁剪、压缩或Worker，不重建已有VFX池和DRS。                                        |
| 局部手感                               | 触控连续死区/尺度、相机平滑、冲刺短缓冲、奖励位置合并分别需要代表场景及取消/方向/多人规则；不得仅凭数量守恒改变奖励可达性。                                    |
| 最小成长诊断                           | 具体自然成长问题需要时补输入方式、干预标记或站点记录；已有runLog/readout直接复用。                                                                             |

真机手柄、手机、字体、正式页面等验收只在已有UI验收change维护。公网长局、自然通关、音频听感与发行验收按相应领域的真实缺口立项；不把历史实验未测清单变成全部已授权待办。
