# 平衡分析手册

数值修改从 [唯一数据索引](../src/run/sim/content/README.md) 开始；玩法契约见 [combat-builds](../openspec/specs/combat-builds/spec.md) 与 [world-progression](../openspec/specs/world-progression/spec.md)。本页只解释分析工具；数值以模拟内容表和模型源码为准，不复制另一份参数表。

## 运行

```sh
# 难度 0/1/2，研究所 none/mid/slots4/luck/party，默认比较四条完整路线
bun run balance:model 0 none
# 单图分析从新玩家开始，用于局部对照，不代表正式路线后图构筑
bun run balance:model 0 none forest 0
# 首关按参考时间挑战，后图进图30秒挑战；等级由连续成长决定
bun run balance:model 0 none campaign 0 510,30,30,30
# 同一连续构筑比较野外事件开启/关闭，并输出逐图收益与模型假设
bun scripts/balance-field-events.ts 0 8 --json
# 机器人仅用于森林走位策略校准，参数以脚本入口为准
bun run balance 0 8
bun test scripts/model.test.mjs scripts/model-survival.test.mjs
```

CLI 参数见 [balance-model.ts](../scripts/balance-model.ts)。输出分 novice / average / expert，每分钟观察等级、输出、受伤压力、生存分布与守卫耗时；模型预设和目标区间是分析假设，不是玩家验收或阻塞门禁。

## 如何判断

先在同一源码、内容表、种子、研究所、路线或单图分析模式下比较前后结果，记录构建身份。用同一参考点比较招式/道具预算，再观察成长和生存曲线。不要同时改变多个参数后把全部差异归给其中一个。

解析模型以存量/流量和期望几何近似推进；离散构筑按种子抽样，先推进每份样本再汇总。机器人覆盖运动和地形，但代表特定策略；真人自然长局才提供真实操作与难度反馈。这三种证据不能互相替代。

`guardian fights` 的 `completed/attempted` 是已击杀/已进入守卫战的样本数。`seconds` 与 `cost`（预期承伤折合最大生命）只对已击杀样本求均值，没有击杀时显示未完成，不把提前死亡截断的消耗当作整场读数。前后完成样本不同会产生幸存样本偏差，比较时必须一并看完成数、通关概率与耗时。追加落点的首次施放、原生招式阶段等待和麻痹延迟采用解析近似；其节拍可能高估或低估实际模拟，不能直接用 `cost` 证明难度倍数。

输出中的 `pressure = capacity / incoming` 实际是清怪供需比：分子为满容量场景下、仅玩家自身构筑的有效清怪能力（HP/s），分母为常规刷新带入的敌人生命（HP/s，含动态供给倍率但未扣活怪上限阻止的生成）。大于1表示理论能力超过供应，小于1表示供应超过能力；它不等于实际受压程度，也不直接控制正式对局刷怪。判断时还要看场上存量、接近时间、精英/守卫分流、同伴、终极技、受伤与生存，不能把该比值强制锁到1。

生命调优从目标击杀耗时反推参考耐久：参考有效单体输出（HP/s）×目标交战秒数，再对照实际物种抗性、可攻击时段及爆发。群怪另看清怪供需与围攻存量。参考构筑用于离线校准；不要把玩家本局每次增伤等比例转换成敌人生命。每次候选都要完整重跑成长，因为击杀变慢会改变经验、宝箱和后续构筑。

运行时增援压力的参数入口为 `content/params/pacing.ts`，实现为 `sim/director-pressure.ts`；`spawnScale` 单独输出最终普通供给倍率。模型共用目标、平滑和供给公式，但使用既有密度与命中率近似观测：均匀密度对距离权重积分得到邻近数量，平稳泊松命中假设得到近期受伤期望。真实空间聚集和伤害突发可能不同，不能把模型的动态反馈当作实局控制器验收。与旧版本比较时须注明是否包含动态增援，历史静态候选结果不代表新闭环。

## 证据与限制

历史数值、公式取舍和校准输出不在仓库中保留；新实验在对应change登记实际日期和基线，不往本手册追加流水账。

野外对照脚本使用同种子的连续构筑，`fieldEvents:false` 只关闭额外事件机制，主线节拍仍按正式时间窗抽取。事件经验、宝箱、同伴和星星沙子在发生的分析步消费，影响后续等级、输出和存活；`income` 是机制归因，`earned` 是实际收益，不能把两者再加到总账。携带蛋跨图保留，满栏孵化卡不经过地上宝箱的拾取概率。地图探索率、引导受击中断和战斗分流属于画像假设，详见该模块的 `FIELD_MODEL_ASSUMPTIONS` 与 `FIELD_MODEL_LIMITS`。CLI 可用 `BALANCE_FIELD_EVENTS=0` 关闭额外机制做配对诊断，不能将不同种子或不同样本数混为前后对照。

终极技读取正式准备与保护时长，准备期间不提前兑现伤害，脉冲按分析步与时间线的交集结算。报告的施放、释放、保护秒数和避免伤害用于核对时序与 HP 过程；瞬时接敌、状态唤醒和空间命中仍是模型近似。

守卫经验与宝箱、神奇糖果即时升级已接入模型。模型仍以敌池平均、聚合存量和几何近似计算；真实旧怪保留出生时生命，模型普通怪存量不逐只记录出生年龄。不能据模型单独下自然通关率结论。受控目标/状态数增伤已计入守卫输出，但通用睡眠唤醒、冻结易伤及真实冷却相位仍未完整重建；诅咒已按占用率近似，需用正式伤害函数校准相应构筑。

调生命时同时看森林开局、两分钟、八分钟和每张后续地图入口。固定构筑对比用于解释伤害与耐久，全程模型用于检查击杀变慢后的经验、宝箱、捕获与成长反馈。头目批次按自身生命成本消耗，额外血量不能换算成更多击杀或奖励；同伴继续读取原共享成长曲线。

## 分岔路线与 AI

森林起步，在沙漠与海岸、冰川与火山各选一张，最后进入紫苑塔。`campaign` 比较这四条组合，每个样本将构筑和生命分布连续带过四张图。`zoneClears` 给出各图到达守卫、击败守卫的概率、完成等级和累计时间。`fights` 记录对应的守卫交战。各图正常阶段至多十分钟，狂暴后可超时。可按图指定召唤秒数，守卫生命、伤害与速度统一读取 `GUARDIAN_REFERENCE_SECONDS`。

路线参数从 `params/campaign.ts` 读取，后图入图时钟在短暂升温后同时承接怪群生命、伤害、速度、刷新、容量与同伴成长；不读取玩家装备来抵消成长。敌人专用耐久倍率仍不应用于同伴。经验、进化及本线招式门槛来自正式模拟定义，模型连续结算前图奖励。

`campaign` 报告把后图前两分钟与前图离开前两分钟并列，同时给出召唤守卫前的纯怪群窗口。窗口读取逐秒探针，按当时存活概率加权；同时看普通/精英存量、积压生命、清怪供需、落地承伤与条件存活。前图末窗包含守卫战，不能把它的承伤全部归于怪群；召唤当秒不计入纯怪群窗口。提前离图造成的截断会标为未完成，完全没有观测时显示为空。调整前后须使用相同种子数、角色和召唤时点；候选与正式模型的小样本数不同，不能当成等条件前后对照。

预判与侧移由真实速度、攻击轨迹、反应延迟和地形共同决定；解析模型的 `skill.dodge`、典型命中与聚合场地没有重建这些几何。这些画像尚未用人类数据重拟合，不能把输出概率称作人类通关率，也不能从局部命中对照推导整局难度倍数。

固定守卫基准、精英/头目耐久调整已与不同召唤时点对照过（2026-11-12）。参考时点用于离线校准，不是玩家挑战门槛；不保证任意构筑获胜或固定击杀耗时。

## 七条玩家线的校准

新增三线沿用参考基础属性的衰减比例：形态 HP 按基础 HP 比值的平方根增长，速度与接触半径分别按基础速度、身高比值的四次根增长。新线起始半径为 0.36 u，进化显示高度也压缩为四次根；最终输入只维护在 `content/lines/*.ts`，推导与声画交接见 [三线设计](../openspec/changes/add-ghost-dragon-fighting-starters/design.md)。

以下为加入三线时的分析参考点：无研究、无背包、完整六关、每关 510 秒召唤守卫、average 画像、32 个固定种子构筑样本。每个数是同一构筑连续走完六图的解析通关概率，不是人类实测或产品门禁；对照所用模型包含毒伤刷新与诅咒占用估算。

| 玩家线   | 普通 | 困难 | 噩梦 | 对比含义                           |
| -------- | ---- | ---- | ---- | ---------------------------------- |
| 小火龙   | 49%  | 29%  | 17%  | 火伤突击                           |
| 妙蛙种子 | 87%  | 70%  | 49%  | 回复与控制，现有上沿               |
| 杰尼龟   | 49%  | 49%  | 30%  | 护甲与护盾                         |
| 皮卡丘   | 73%  | 55%  | 37%  | 速度与麻痹                         |
| 鬼斯     | 63%  | 37%  | 17%  | 诅咒、毒伤与闪避                   |
| 迷你龙   | 73%  | 53%  | 29%  | 前期龙伤受限，进化后贯穿成长       |
| 腕力     | 72%  | 43%  | 28%  | 近身连打与进化增伤，高难度仍处下沿 |

固定参考构筑（10 级、四招 kit 各两次期望强化，森林 5:00、普通难度）的清怪/单体 HP/s：旧四线约 122–160 / 98–160；鬼斯约 164 / 109，迷你龙约 125 / 84，腕力约 141 / 125。此点刻意保留迷你龙的慢热；不能把未进化时的低单体输出当作全程失衡。腕力初始仅计护甲的 EHP 为 187.5，旧线同口径为 96–118.75（未计护盾、回复、闪避或克制）；其近战接敌损失由模型的 melee 参数单独计算。

腕力的参考值采用已修正的连击模型：普通拳重复命中同一锁向扇区，不按拳数增加独立目标；终极技计入属性增伤。普通难度 novice / average / expert 六关解析通关率约为 12% / 72% / 100%；average 到 L16 约 7:15，8:00 已到 L17（当时仍运行样本的平均等级为 17.6）；novice 最后一次观测的守卫到达 TTK 约 88 秒。百裂拳在 8:00 中性属性参考点，相对两招满级中位招式的清怪/守卫输出为 1.07× / 1.44×，分别落在 1–1.8× / 0.4–1.5× 的分析区间。空手劈和下盘踢以施放频率与近身覆盖改善成长，百裂拳减少同目标过量伤害、扩大短程扇区，毅力在进化后补足单体成长；仍保留锁向连打、末拳强化与近战接敌要求。这些数值尚未由真人操作校准。

状态模型仍有边界：毒与灼伤在守卫上分别按最强施加命中和刷新占用率计算，诅咒按占用率近似易伤；群怪 DoT 在单次施放内合并，跨招式共享同一存活目标的精确相位尚未重建，可能高估重叠施毒。终极技的状态占用与唤醒时点也未逐脉冲重放。上述概率用于判断相对强弱，正式走位和声画仍需实际游戏验收。
