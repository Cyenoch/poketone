# Spec Delta

## ADDED Requirements

### Requirement: 大厅模式入口

网页大厅 SHALL 提供进入据点模式的入口，和生存模式的出发分开，用键鼠、触控或手柄都能到达。入口 SHALL 显示世界存档位的状态，并提供继续或新建。进入世界 SHALL 只提交一次。原生端在支持据点模式之前 MUST NOT 显示该入口。

#### Scenario: 连续确认进入世界

- **WHEN** 玩家确认继续世界后，资源仍在准备，又按了一次确认
- **THEN** 保持同一次载入，不重复读取存档，也不创建第二个世界

#### Scenario: 原生端的大厅

- **WHEN** 玩家在原生 SDL 应用中打开大厅
- **THEN** 没有据点模式入口，生存模式的出发和其他大厅功能不受影响

#### Scenario: 从据点世界返回大厅

- **WHEN** 玩家退出据点世界
- **THEN** 世界先完成保存或明确报告保存失败，然后回到大厅，生存模式的选择保持不变

### Requirement: 据点跟随镜头

据点世界的镜头 SHALL 跟随训练师，默认高角度俯视。镜头拉近时俯角变低，拉远时接近俯视，MUST NOT 进入越肩视角。

#### Scenario: 拉近镜头

- **WHEN** 玩家把镜头拉到最近
- **THEN** 俯角变低，训练师仍在画面中，不切换成越肩视角

## MODIFIED Requirements

### Requirement: 上下文恢复后继续游玩

图形上下文丢失与恢复 SHALL 保留可恢复的游戏状态，重新准备必要 GPU 资源并允许继续、放弃和重开；不将失效资源带入下一局或下一次进入的据点世界。

#### Scenario: 恢复后开始新局

- **WHEN** 对局遇到 context loss，恢复后继续，再放弃并重新出发
- **THEN** 世界与 UI 正常绘制，动态窗口可关闭，不出现跨 context 资源错误

#### Scenario: 据点世界中丢失上下文

- **WHEN** 据点世界遇到 context loss，恢复后继续游玩，然后返回大厅，再次进入世界
- **THEN** 世界状态不丢失，建筑、单位和界面正常绘制，不出现跨 context 资源错误
