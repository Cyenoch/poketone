# Spec Delta

## MODIFIED Requirements

### Requirement: 画面不改变玩法

呈现层 SHALL 只读取模拟结果，不绕过指令边界写入玩法状态。生存模式的视野参数 SHALL 作为确定性输入进入模拟，允许影响视野选敌与刷怪；据点模式不接收视野参数，遵守 base-world 的「规则不依赖镜头」。纯视觉插值 MUST NOT 反向改写模拟世界。

#### Scenario: 同一对局以不同显示帧率绘制

- **WHEN** 固定步长模拟的初始状态和全部指令（包含视野参数）相同，仅其结果的绘制频率不同
- **THEN** 该固定步长模拟结果保持一致，只有呈现采样不同；不据此宣称联机本机碰撞在任意呈现调度下完全相同

#### Scenario: 据点世界不接收视野参数

- **WHEN** 据点世界运行时，玩家移动、缩放镜头或进入建造模式
- **THEN** 发给模拟的指令不含任何视野参数，生存模式的视野选敌与刷怪规则不受影响
