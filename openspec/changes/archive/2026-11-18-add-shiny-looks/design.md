# Design

## 所属版本

大版本「野外与路线」。共用约定见 [野外与路线规划](../2026-11-18-add-field-events/design.md#共用约定)。依赖 `extend-progress-v5`、`add-field-events`。羁绊 Lv5 授予由 `add-partner-bond`（在本 change 之后）写入同一个 `looks.owned`，本 change 不依赖它。

## 技术方案：着色器调色板替换

读过模型与材质加载路径后的结论：

- 每个形态的 GLB 只有一张 `baseColorTexture`。局内 `lambertCopy` 复制 `map`，敌人逐物种用 `patchShader` / `inject` 改着色器（`view/enemyLook.ts`）。
- 大厅转台用 `instantiate(canonical)`，材质、几何和贴图与模型仓库共享。

多数形态使用片元着色器替换配色。需要按身体部位区分相近色相的形态使用同 UV 底图。

- `view/shiny.ts` 汇合 `add-field-events` 已登记的敌人配色和 `assets/shiny-forms/palettes.json` 的伙伴补充配色。着色器将所选色相平滑映射到目标色相，对低饱和区域可单独着色。
- `view/materials.ts` 为玩家实例应用该调色或使用已加载的同 UV 贴图。离线头像生成器读取相同的形态表。
- 局内：玩家网格在 `lambertCopy` 之后按需套用 `shinyLook`，材质本来就是每实例一份，不影响他人。
- 大厅：异色时为转台副本克隆材质再套用，不改动仓库的共享材质；释放时只释放克隆的材质。上下文丢失和恢复沿用转台现有的释放与重新编译路径。
- 进化时换模型，新形态按同一外观重新套用。
- 着色器按调色功能缓存程序，配色参数属于材质实例。合作中同形态的普通玩家和异色玩家可以同时显示。
- 小火龙、火恐龙、喷火龙需要保留尾焰，卡咪龟和水箭龟需要区分背甲与腹甲。胡地、快龙、鬼斯、鬼斯通、哈克龙和小拳石系列的三个形态也使用局部遮罩，分别处理护甲、翼膜、雾气、口腔、宝珠或岩体。烘焙工具从正式 GLB 提取静止网格、原 UV 和内嵌底图。各形态的配方和来源在 `assets/shiny-forms/` 登记，游戏通过资源清单加载十三张异色底图。

## 配色依据

按官方异色配色（例如小火龙系列偏金黄，喷火龙为黑色，杰尼龟系列偏蓝紫，妙蛙种子系列偏黄绿）。每个形态渲染一张侧视对比图（普通 / 异色），由 Claude 看图确认后登记。参考来源写进 `assets/` 下该形态的 provenance。

## 头像

- 头像是 2D 立绘（`/art/portraits/<form>.webp`），出现在大厅、房间座位、局内队友条和屏外标记。
- 新脚本 `scripts/shiny-portraits.mjs` 读同一张调色参数表，对头像做同样的 HSV 映射，输出 `<form>-shiny.webp`，登记来源。有兜底贴图的形态，头像参数可以单独调整。
- 头像按普通路径通过 `fetchAsset` / `assetUrl` 取用，发布构建带内容哈希。

## 获得

- 进度 v5 `looks.owned: StarterId[]`。
- 击败异色：结算时，本局击败的异色物种（`Player.dex` 的 `shiny` 计数）如果属于某伙伴系列，就把该系列加入 `owned`。系列成员由 `lines/<line>` 的形态表推导，不手写映射。和其他局外奖励一起只入账一次。
- 羁绊：`add-partner-bond` 的里程碑直接写入 `owned`。
- 伙伴系列的形态目前不全作为敌人出现（小火龙、杰尼龟、妙蛙种子、皮卡丘系列不会），这些系列只能通过羁绊获得。本 change 不为此新增敌人生成。

## 切换与开局

- 大厅：选中已拥有异色外观的伙伴时，伙伴展示区出现一个闪光图标开关；没有拥有时不出现。切换后立即更新转台模型与头像，并写入 `looks.worn`。
- `RunConfig.players[]` 新增 `shiny: boolean`。只影响外观，sim 不读取，不进入世界状态，golden 不变。
- 合作：座位信息带上 `shiny`，队友的座位头像、局内模型、队友条和屏外标记都用异色。房主不能更改别人的外观。
- 图鉴：伙伴形态条目里，拥有该系列外观时可以切换模型预览为异色。

## 测试

- 进度：击败异色系列成员时获得一次；非伙伴系列的异色不授予；重复结算不重复。
- 外观不影响模拟：同一种子开关异色，世界 digest 相同。
- 视图（`view.test.mjs`）：两个同形态实例一普通一异色时，材质互不影响；转台释放后共享材质未被修改。
- 头像：每个形态的异色头像存在，并能通过资源清单找到。

## 不做

- 不做新模型，不做额外配色（只有普通和异色）。
- 不做敌人异色之外的外观来源，不做任何购买。
