# Design

遵守 [野外与路线规划](../archive/2026-11-18-add-field-events/design.md#共用约定) 的共用约定。只用正作的名称和机制：喷火龙进化石Ｘ / Ｙ、超级喷火龙Ｘ / Ｙ、硬爪、日照、闪焰冲锋。

## 现状

- **形态**：`content/lines/charmander.ts` 是小火龙 → 火恐龙（28）→ 喷火龙（55）。喷火龙的属性为火 / 飞行，hp 141，speed 4.4，radius 0.464，height 1.6。特性 `blaze`，终极技 `blast-burn`。
- **招式**：本线 kit 是火花、火焰旋涡、喷射火焰、大字爆炎，进化招式是喷烟、鬼火，全部是特殊招式。
- **形态读取**：`evolution.ts` 的 `formOf(player)` 由 `stageForm(starter, stage)` 给出形态。`evolve` 补新增的最大生命、给 `EVOLVE_INVULNERABLE` 无敌并设置 `cardHold`。`evolveInWorld` 推送 `{ t: "evolve", player, stage, form }`。
- **画面**：`view/assets.ts` 的 `formModels` / `facingYaw` 把形态 ID 映射到 GLB 模型和朝向修正。
- **终极技**：`content/ultimates.ts` 与 `ultimates/` 提供充能后施放的限时爆发，有自己的充能条、`player.ult` 状态和演出。
- **前置 change**：
  - `deepen-builds` 引入 `player.ability` 和不变之石。
  - `add-route-branches` 引入守卫奖杯三选一。
  - `add-field-events` 引入 `world.weather`。

## 决定一：永久形态分支，而不是限时状态

超级进化做成**本局永久的形态分支**：选定进化石之后，喷火龙一直保持超级形态，跨图保留。

理由：

1. **正作语义**：超级进化持续整场对战，进化石 X 和 Y 是两条路线。限时变身、几回合后变回去，是极巨化的特征。把超级进化做成限时，宝可梦玩家会觉得不对。
2. **不和终极技重复**：终极技已经是"充能 → 限时爆发"。再加一个限时变身，就会有两条充能条争同一个高光时刻，HUD 也要多一套状态。
3. **复用现有形态管线**：`formOf`、进化事件、模型切换、平衡模型本来就处理永久形态。限时变身需要在战斗中来回切换模型，还要处理变回时的生命折算、快照里的计时器，以及两次演出，成本高，出问题的地方也多。
4. **数值有界**：永久分支在模型里就是"最终形态之后多一个阶段"。代价是进化石占一个道具栏、不能升级，并且第 2 张图起才可能拿到。这样强度上限可以预先算出。

放弃的东西：限时变身"关键时刻开大"的爽感。不过超级进化发生的那一刻本身就有一次演出，开大的爽感仍由终极技负责。

## 决定二：数据结构

```ts
// content/lines/index.ts
export interface MegaDef {
  id: MegaId; // "charizard-x" | "charizard-y"
  stone: ItemId; // "charizardite-x" | "charizardite-y"
  form: FormDef; // 超级形态：属性、生命、速度、体型、ref
  ability: AbilityId; // 覆盖 player.ability
  moves: readonly [MoveId, ...MoveId[]]; // 全部加入候选池，首招另有一次专属学招卡
}
export interface LineDef {
  /* … */ megas?: readonly MegaDef[];
}

// state/entities.ts Player
mega: MegaId | null;
```

- `formOf(player)`：`player.mega` 不为空时返回超级形态，否则走原来的阶段形态。所有读取形态的地方（体型、属性、模型、命中体积）自动跟着变。
- 特性：超级形态的特性覆盖 `player.ability`。特性数值按最终阶段的下标读取。
- 招式池：`upgrades.ts` 的可选招式加入 `mega.moves`，规则和 `evolutionMoves` 一样。
- 终极技仍是爆炸烈焰，只按形态属性给 VFX 换色：X 用蓝焰，Y 保持橙焰。

|          | 超级喷火龙Ｘ                                                                                   | 超级喷火龙Ｙ                                                 |
| -------- | ---------------------------------------------------------------------------------------------- | ------------------------------------------------------------ |
| 属性     | 火 / 龙                                                                                        | 火 / 飞行                                                    |
| 特性     | 硬爪：物理招式伤害 ×1.3                                                                        | 日照：超级进化时和每次进入地图时，天气变为大晴天并持续 30 秒 |
| 数值方向 | 物理伤害与护甲提高                                                                             | 特殊伤害提高                                                 |
| 新招式   | 闪焰冲锋（新增，物理火系冲撞，命中时自身损失少量生命，对应正作的反作用伤害）、龙之俯冲（已有） | 日光束（已有，晴天冷却减半）、暴风（已有）                   |

具体数值由解析模型校准：X 和 Y 分别作为最终阶段之后的一个阶段，与不超级进化的喷火龙对照。

## 决定三：获得与触发

- **进化石**：喷火龙进化石Ｘ（`charizardite-x`）和喷火龙进化石Ｙ（`charizardite-y`）。传说品质，最多 1 个，不能升级，占一个道具栏。正作里进化石是携带道具，也占携带位。
- **来源**：只来自守卫奖杯，路线第 2 张图起。
  - 符合条件的玩家：小火龙线，没有持有不变之石，本局还没有超级进化。
  - 这类玩家的奖杯三选一里，两个选项固定是 X 和 Y 两块进化石，第三个是普通奖杯候选。不选也可以，之后的守卫奖杯会再次提供。
  - 道具栏满时仍提供进化石。选项标明将丢弃的非进化石道具：等级最低者优先，同级取最早获得者。房主提交时重验；若目标改变，刷新卡片再选择，不静默丢弃另一件道具。
  - 引梦貘人不列出也不能遗忘超级进化石。持石后不再提供不变之石；局外背包不能带入超级进化石。
- **触发**：持有进化石并且当前形态是喷火龙时，进入超级进化。
  - 如果在火恐龙阶段就拿到进化石，等进化成喷火龙、`cardHold` 结束后再超级进化。两次演出不叠在一起。
  - 超级进化复用 `evolve` 的规则：补新增的最大生命，给无敌时间，`cardHold`。
  - 推送新事件 `{ t: "mega", player, form }`，画面以此播放专属演出。
  - 超级进化的 `cardHold` 结束后，房主为该玩家排一张专属学招卡：Ｘ学闪焰冲锋，Ｙ学日光束。已会则不出卡。有空栏直接学，满栏时每个原招各有一个替换选项；都可选择不学，不花跳过次数。替换仅重置所选招式为新招一级。
- **不需要钥石**：正作需要训练家持有钥石。本作没有训练家，直接以进化石为准，不另加道具。
- **合作**：每名玩家的奖杯和超级进化都是个人收益，由房主结算。两名小火龙线玩家可以分别走 X 和 Y。

## 画面与资产

- **模型**：超级喷火龙Ｘ / Ｙ 走 `.agents/skills/skill-model/` 的多视图流程：
  - 官方立绘 → nano banana 2.1 设定图 → 拆分 → multiview-to-model。
  - 参数：`smart_low_poly=true`，`face_limit` 500–1500，先 `--dry-run`，`TRIPO_CLIENT_APP=claude`。
  - 每个约 40 积分，在旁边记录来源。
  - 渲染侧视图确认朝向后，再写 `facingYaw`。
- **演出**：进化演出加超级进化专属的七彩光球与外壳碎裂效果，按 `skill-vfx` 流程制作。X 的火焰粒子用蓝色。
- **音效**：超级进化 1 个、闪焰冲锋 1 个，走 ElevenLabs 与母带流程，按 `timing.json` 对齐关键帧，遵守舒适音量规则。
- 图鉴收录两个超级形态，`dex` 字段沿用 `extend-progress-v5` 的定义。

## 后续内容

本作现有最终形态中，正作有超级进化的还有以下几只。每只各需 1 个模型，各自单独立项：

| 形态   | 超级形态特性 | 本作翻译方向                                   |
| ------ | ------------ | ---------------------------------------------- |
| 妙蛙花 | 厚脂肪       | 受到的火系、冰系伤害减半                       |
| 水箭龟 | 超级发射器   | 波动类招式伤害与范围提高（需要水之波动等招式） |
| 耿鬼   | 踩影         | 附近的精英和守卫无法远离（减速）               |
| 胡地   | 复制         | 复制附近精英或守卫的属性增伤                   |

快龙和雷丘（X / Y）在《宝可梦传说 Z-A》及其追加内容中已有超级进化，本版本不做，留作后续内容（需要新模型）；怪力、隆隆岩在正作中没有超级进化。

## 数值（平衡建议）

模型对照、敏感度和局限见 `docs/BALANCE.md`「超级进化」。设计意图不变，数值如下，实现按此填入：

| 项目                                                                    | 超级喷火龙Ｘ                                                                                                                      | 超级喷火龙Ｙ                       |
| ----------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------- |
| 最大生命（相对喷火龙）                                                  | +14                                                                                                                               | +10                                |
| 速度                                                                    | +0                                                                                                                                | +0                                 |
| 伤害方向（形态自带修正，不是特性；`MegaDef` 需要一个 `modifiers` 字段） | 护甲 +8                                                                                                                           | 特殊招式伤害 ×1.35                 |
| 特性                                                                    | 硬爪：物理招式伤害 ×1.30                                                                                                          | 日照：进化时和每次入图 30 秒大晴天 |
| 习得招式                                                                | 闪焰冲锋：火系物理波，威力 50，冷却 3.2 秒，10% 灼伤，每次成功施放支付一次反作用：0.2% 最大生命（非致死，多条波或多只目标不叠加） | 日光束（现有数值）                 |

- 专属卡不占一次升级，也不增加招式栏；即使拒学，超级形态招式仍在常规候选池中，按原有规则出现。
- 进化石占 1 个道具栏，第 2 张图守卫奖杯取得。
- 结果（average，难度 0）：终局通关率 +2–6 个百分点，Ｘ 与 Ｙ 的均值差不到 1 个百分点；第三张图Ｙ的群怪输出约 +25–30%，Ｘ 约 +2%；紫苑塔压力指数 1.53–1.67 → Ｘ 1.83–1.97 / Ｙ 2.08–2.32。
- 闪焰冲锋按预算口径偏高（群怪 3.42×、守卫 2.18× 中位数，含硬爪更高），原因与取舍见 BALANCE.md；实现后需用 sim 的真实招式重测一遍。

## 风险

- 永久强化可能让后两张图失衡。先跑模型对照，把进化石的道具栏代价和第 2 张图之后才能拿到这两点计入。
- Ｘ的物理方向依赖闪焰冲锋；专属学招卡保证满栏玩家也能选择它，但不强迫放弃已经强化的招式。
- 日照与野外天气、求雨（`deepen-builds`）会互相覆盖，按正作"后施放者覆盖"的规则处理。
