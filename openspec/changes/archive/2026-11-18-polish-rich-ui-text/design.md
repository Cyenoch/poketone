# Design

## 富文本

UIKit 的 Text 一个节点只有一种颜色，没有内联片段。`rich-text.ts` 自己断行（沿用 `breakLines` / `balanceLines` 的禁则与数字不拆），每行由文本、数值和属性片段组成一行容器。属性徽记在断行时以私用码位 `ICON_MARK` 占位，宽度按徽记计算，并且不留在行尾。片段首尾空格由 UIKit 从宽度中去掉，因此转为边距。

数值颜色：深色提示底用 DESIGN `yellow`；局内浅色表面用当前属性主题的 `deep` 档。不另设伤害、治疗、时长的语义色，DESIGN 中没有这些令牌。

属性只在写作「X属性」时带徽记：单字属性名也出现在普通词中（冰冻、中毒）。17 个属性都有徽记（`/art/icons/crests/<type>.webp`），只经 `src/ui/gpu/type-icon.ts` 取用。属性标签全站一种：navy-deep 斜切签，徽记 + 白字属性名，各界面只改字号；紧凑行（HUD 名牌放不下时、构筑面板招式行）只留徽记。图鉴的属性名写作「X属性」，经富文本带徽记。

## 提示

`Tooltip.show` 接受字符串或条目列表。条目由图标、名称、可选冷却和富文本效果组成，块间用细线分隔。训练师条的提示放在其右侧，不再遮住训练师名牌。

## 构筑面板

战况数字合为一条浅色带并以细线分隔；短横屏改为数字与名称同行。可选属性仅在有来源或数值离开基础值时显示（规则造成的变化没有来源，但会改变数值）。
