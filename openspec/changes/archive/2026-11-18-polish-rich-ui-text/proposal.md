# Proposal

## Why

招式、道具、特性和训练师效果里的数值与正文同色，读不出重点；属性只写成文字。训练师道具和被动挤在一段提示里，冷却混在句中。局内构筑面板的五个独立数字框过重，「属性」页列出大量未被改变的 100% 行。

## What Changes

- 共用富文本：说明里的数值按所在表面着色，写作「X属性」的属性在名称前带属性徽记；属性标签也带徽记。
- 训练师提示分成道具和被动两块，各有图标与名称，冷却为紧凑标记，提示放在训练师条右侧。
- 构筑面板：「战况」数字合为一条，招式名旁为属性徽记，数据和道具效果使用富文本；「属性」页隐藏没有来源且仍为基础值的可选属性，被改变的值着色。
- 升级卡说明使用同一富文本。

## Capabilities

### New Capabilities

无。

### Modified Capabilities

- `gpu-presentation`：说明文字的数值与属性呈现、训练师提示结构、构筑面板的层级。

## Impact

仅 GPU 表现层（`src/ui/gpu/`）与训练师提示数据；不改模拟、数值或存档。
