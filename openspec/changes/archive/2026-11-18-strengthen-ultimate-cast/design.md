# Design

## Context

需求见 [proposal](proposal.md)。`ultimates/index.ts` 目前在接收命令后直接推进脉冲，`params/ultimates.ts` 的保护为一秒；`trainer-cues.ts` 的本机切入为 1300ms。横幅已有 GPU 斜切底板、立绘、属性徽记、速度线与清理规则，沿用这些组件和 [DESIGN](../../../DESIGN.md)。

## Goals / Non-Goals

准备与释放在共享模拟中明确区分，保护不依赖动画或显示帧率。保留各角色原有脉冲相对时序、伤害和覆盖范围，以及主动移动和冲刺；不扩大到大厅重设计或其他训练师验收。

## Decisions

- 五秒从命令被接受起算，包含两秒准备。`UltState` 保存独立剩余保护时间，避免原技能最后一脉冲早于五秒时过早失去保护；共享世界与拥有者模拟各推进自己的副本，沿用现有无敌期的状态同步，不在攻击执行器重复扣时。
- 每次成功施放递增 `cast`。房主接收同一次施放的 owner 包时，保护剩余量只减不增；拥有者恢复本机动作状态时保留自己的倒计时，不把房主已扣的余额再回灌，防止两端叠加扣时。事件保留首次产生的年龄，背压、重传及转发不重新计龄。
- 联机以本机即时响应、移动与施法连续为先，不做反作弊。F 演出归属读取已知发送席位及其进化线；无法显示的档位或事件年龄只丢弃该演出，同包移动与命中照常接收。旧施放随较新消息到达时保留当前施放，不把动作整包拒绝；保留避免非有限数和缺失状态破坏正常对局的结构边界。
- `ult` 表示开始，新增 `ult-release` 表示两秒准备完成。脉冲读取准备后的相对时间，强音效与释放强调接后者，训练师切入接前者。沿用事件年龄丢弃过期反馈。
- 保护统一覆盖常规伤害、毒与天气持续伤害，以及敌方施加的控制和推拉；天气的不可减免规则在终极技无敌期间不扣血。霸体不穿墙、不越过地形碰撞；已有控制解除，毒状态可继续计时而不造成伤害。
- 切入由 Opus 按 impeccable 优化：本机采用约三秒的入场、可读停留、释放强调与退场；实际释放事件校正强调时刻。强化立绘、属性色边缘和速度线，限制闪白面积，保留战场、生命和操作区。多人仍优先显示本机，不堆积过期队友横幅。
- 新世界字段随本批快照版本升级，旧世界快照明确拒绝。进度格式不变。主线程保留各 change 的独立补丁与验证证据；两个模拟实现者继续保持文件分工。

## Risks / Trade-offs

- 五秒保护提高生存能力 → 模型引用共享时长并重跑代表性构筑，golden 按有意行为变化记录。
- 跨伤害路径漏接或多人重复推进 → 定向覆盖直接伤害、持续伤害、控制与共享/本机步进；恢复测试比较续跑。
- 长横幅遮挡小横屏 → 1280×800 与 844×390 正式页面截图及动态录制，验证输入与清理。合成输入不作为物理设备证据。

## Migration Plan

先落模拟与事件接口，再接 GPU 切入与声音；统一检查、不同 provider 审阅、规范同步后本地提交。任何未完成验收保持未勾选。
