# Proposal

## Why

用户要求新增鬼斯、迷你龙、腕力三条可操控进化线，让诅咒游击、后期穿透与近战连击成为可选玩法。现有四条线与敌人物种保持原定义。

## What Changes

- 追加三条玩家线、九个准确物种形态 ID、各自四招招牌技能、两招进化技能、特性和三档终极技。
- 为近战加入前向连续拳击与末击强击退；其他攻击复用现有原型及状态。
- 补齐每条线必需的融合配方，复用现有融合执行设施。
- 解析模型纳入玩家毒伤，并比较七条线在三难度的连续成长；补充确定性回放与针对性行为测试。
- 模型、VFX、音频及大厅由并行实现者接入，交接以 design 中的 ID、阶段和几何为准。

## Capabilities

### New Capabilities

无。

### Modified Capabilities

- `combat-builds`: 增加三条可控进化线与前向连击的行为契约。
- `balance-tuning`: 持续伤害构筑的解析模型覆盖毒伤及不叠加规则。

## Impact

影响 `src/run/sim/content`、`archetypes`、`src/run/balance`、模拟测试与 golden。新增内容沿用种子随机、共享快照和升级系统，不修改敌人 ID，不新增存档兼容层或依赖。资产与呈现不在本实现者所有权内，正式视觉/听觉验收留给整合工作。
