# Proposal

## Why

用户反馈（2026-11-17）：把守卫拉离召唤地标后击败，玩家不知道该去哪离开。原出口在地标上，清区后只把地标光柱换成很淡的米色，远处几乎看不见。

## What Changes

- 守卫倒下的位置开出出口（参考以撒的结合：Boss 死后原地出现活板门）。落点必须站得下、能与地标双向往返，并且不和站点的交互范围重叠；不满足时（比如飞行守卫倒在水面、单向悬崖或岩石上）就近找符合条件的位置，都找不到时退回地标。
- 地标只负责召唤守卫，清区后熄灭，不再作为出口。
- 出口在世界里显示为一圈亮环和高光柱，小地图显示带「出口」标签的青色标记，超出范围时贴边并指向出口，罗盘也指向出口。
- 交互入口改名为 `zoneAction` / `interactInZone`，召唤与离开的条件保持不变。

## Capabilities

### Modified Capabilities

- `world-progression`：守卫与出口结算。
- `gpu-presentation`：守卫与倒地队友的位置提示（清区后的出口标记）。
