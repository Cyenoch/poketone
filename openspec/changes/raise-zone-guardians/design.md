# Design

## Context

用户确认：只需用大致时间点校准参考战力；玩家可以在30级前后召唤，打不过不代表模型必须兜底。现有六关模型每图8:30召唤，运行守卫却使用实际召唤时间，未覆盖前图成型后早召。2026-11-10 的旧三区强化读数不能作为当前六图耐久验收。

## Goals / Non-Goals

目标是同图同难度同人数面对固定守卫基础挑战，保留成长带来的优势；按统一参考点校准敌人角色层级。不要求每种路线都通关、不锁等级、不强制等时、不保证固定TTK，不穷举玩家决策。

## Decisions

- 先沿用每关510秒作为离线参考时点，来源归于玩法参数。守卫生命、伤害、移动速度均以此计算；实际召唤时刻只决定何时进入战斗，不再改变出生属性。普通怪原有生命下限、伤害/刷新时钟与狂暴供给照常运行。
- 地图、难度、席位倍率继续从已有参数应用一次。守卫本身不随狂暴实时补属性；狂暴仍提升增援，与当前生命周期一致。
- 保留现有局内微调：队伍近身敌群、近期受伤、最大生命比例及倒地状态继续平滑调节普通增援，玩家道具的刷新率/精英率和敌人基于进程的预判/躲避继续生效。固定的是守卫出生基准，不取消这些反馈，也不新增按伤害同比加血。
- 降低精英/头目额外耐久，保留它们的伤害、经验、掉落和身份。具体候选通过同条件连续成长与固定构筑对照确定；更快击杀带来的经验增长必须一起记录。
- 模型允许可选逐关秒数数组，默认仍是参考时点；仅支持确定性时间参数，不增加策略引擎或运行时开关。比较默认路线、首关参考时点后图早召和全部早召即可暴露强度对召唤时刻的错误依赖。
- 修正模型受控目标/状态数增伤对守卫的遗漏。明确几何、接触率和状态占用仍为近似，正式伤害函数靶场用于校准，不宣称真人胜率。
- 已有强化攻势和取消规则保留。旧“第二/三区2×/5×”验收目标由用户确认的固定地图挑战取代，真人联机预警可读性继续作为未完成验收，不伪造结论。

## Risks / Trade-offs

- 早召固定强度守卫会比原来难，符合用户选择；晚召玩家成长更完整，依然可以打得快。
- 精英变薄会增加可取得的经验、宝箱与同伴，需要重新跑连续模型，不能只看单只HP。
- 不同构筑输出与接触距离差异很大；参考点只是调参基准，解析概率不等于人类通关率。真实地形和真人联机验收范围须单独说明。
