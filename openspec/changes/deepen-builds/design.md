# Design

遵守 [野外与路线规划](../archive/2026-11-18-add-field-events/design.md#共用约定) 的共用约定和原则：只用正作已有的机制、道具与特性；随机只用世界 rng；共享结果由房主结算；内容写成带稳定 ID 的数据表。

## 现状

- **进化**：`content/lines/index.ts` 中，`LineDef.stages` 由 `EvolveStage { kind: "evolve", at, form }` 和 `MatureStage { kind: "mature", at }` 组成。`evolution.ts` 的 `stageFor(line, level)` 只看等级；`evolve(player)` 补新增的最大生命、给 `EVOLVE_INVULNERABLE` 无敌并设置 `cardHold`；`evolveInWorld` 推送 `evolve` 事件。`upgrades.ts:196` 用 `evolutionMoves.slice(0, player.stage)` 开放进化招式。
- **进化奇石**：`items.ts` 里已有 `eviolite`「进化奇石」，带 `when: "canEvolve"` 条件的护甲和最大生命加成。`stats.ts:204` 的 `canEvolve(player)` 判断后面还有没有 `evolve` 阶段。
- **雷之石**：`items.ts:477` 已有 `thunder-stone`「雷之石」，是一个暴击触发电击的史诗道具。
- **特性**：`LineDef.ability` 每条线一个，`stats.ts:187` 按 `player.stage` 读取分阶段数值。现有特性中，猛火、静电、毅力、同步、结实是正作名；光合作用、激流之壳、幽影、龙鳞不是。
- **融合**：`fusions.ts` 的 `signatureFusions` 每条线只有一个配方；`fusion.ts` 的 `fusionStatus` 要求两件原料都满级。
- **反应**：`reactions.ts` 有 shock（潮湿 + 电）、steam（灼伤 + 水）、wildfire（灼伤 + 草）。
- **天气**：由 `add-field-events` 引入 `world.weather`（种类与剩余时间）以及各天气的属性修正，本 change 直接使用。

## 决定

### 1. 进化条件

```ts
// content/lines/index.ts
export interface EvolveStage {
  kind: "evolve";
  at: number;
  form: FormDef;
  needs?: "thunder-stone" | "trade";
}
```

- `stageFor` 改为 `stageFor(player)`：等级到了，并且 `needs` 已满足，才进入该阶段。持有不变之石时一律不进化。`canEvolve` 不受影响，它只看后面有没有进化阶段，所以持有不变之石时进化奇石始终生效。
- **皮卡丘 → 雷丘**：正作只能用雷之石进化。雷丘阶段加上 `needs: "thunder-stone"`，持有雷之石且等级达到 54 就进化，雷之石原有的暴击效果不变。
- **电气球**（`light-ball`，史诗）：新增道具，只对皮卡丘形态有效，皮卡丘的招式伤害 ×1.5。正作里电气球让皮卡丘攻击翻倍，这样"留在皮卡丘"就有自己的数值方向。进化成雷丘后电气球不再生效，道具保留。
- **通信进化**：豪力 → 怪力、鬼斯通 → 耿鬼、勇基拉 → 胡地、隆隆石 → 隆隆岩，最终阶段加上 `needs: "trade"`。满足方式有两种：
  - **合作交换**：两名玩家相距 2.5 以内，先后对彼此按交互，间隔不超过 5 秒，由房主结算。双方中满足等级的通信线玩家立刻进化。不是通信线的玩家没有效果，正作里交换不进化的宝可梦也没有效果。
  - **联系绳**（`linking-cord`，史诗，最多 1 个）：阿尔宙斯里的道具。持有时满足交换条件，进化发生时消耗并腾出道具栏。
  - 等级达到后还没交换的通信线玩家，守卫奖杯候选里必定有联系绳，保证单人也能进化。
- **不变之石**（`everstone`，稀有，最多 1 个）：持有时不进化。它和进化奇石配合，就是"要不要进化"的真选择。没拿到的进化招式不开放，代价写在规则里，不另加说明文字。
- 所有进化仍走 `evolve` / `evolveInWorld`：补新增的最大生命、给无敌、推送事件，规则不变。

### 2. 正作特性与隐藏特性

正作的特性按**形态**定义，进化时保留的是“特性栏位”（第 1 / 第 2 普通特性或隐藏特性），不是特性本身。例如鬼斯通的浮游在进化成耿鬼后变成诅咒之躯，哈克龙的神奇鳞片在进化成快龙后变成多重鳞片。照此建模：

```ts
// content/lines/<line>/forms：每个形态
abilities: { normal: readonly [AbilityId] | readonly [AbilityId, AbilityId]; hidden?: AbilityId }
// state/entities.ts Player
abilitySlot: 0 | 1 | "hidden"   // 开局 0
// 当前特性 = 当前形态 abilities 按栏位取；栏位 1 而该形态只有一个普通特性时取第 1 个（正作同样如此）
```

| 线       | 形态           | 普通特性        | 隐藏特性 |
| -------- | -------------- | --------------- | -------- |
| 妙蛙种子 | 全部           | 茂盛            | 叶绿素   |
| 小火龙   | 全部           | 猛火            | 太阳之力 |
| 杰尼龟   | 全部           | 激流            | 雨盘     |
| 皮卡丘   | 皮卡丘、雷丘   | 静电            | 避雷针   |
| 鬼斯     | 鬼斯、鬼斯通   | 浮游            | —        |
| 鬼斯     | 耿鬼           | 诅咒之躯        | —        |
| 腕力     | 全部           | 毅力 / 无防守   | 不屈之心 |
| 迷你龙   | 迷你龙、哈克龙 | 蜕皮            | 神奇鳞片 |
| 迷你龙   | 快龙           | 精神力          | 多重鳞片 |
| 凯西     | 全部           | 同步 / 精神力   | 魔法防守 |
| 小拳石   | 全部           | 坚硬脑袋 / 结实 | 沙隐     |

- **改名并调整效果**：光合作用 → 茂盛，激流之壳 → 激流，幽影 → 浮游（耿鬼为诅咒之躯），龙鳞 → 蜕皮（快龙为精神力）。效果改成正作含义的自动战斗版本，例如茂盛是低生命时草系增伤。数值先在模型里对齐原来的强度。
- **二选一**：有两个普通特性的线（腕力、凯西、小拳石），第一次进化时的选择对话里给出两个特性，选的是栏位。新增 `Choice` 种类 `ability`，复用现有选卡对话。只有一个普通特性的线不弹这个选择。
- **特性膏药**（`ability-patch`，传说）：正作中把特性换成隐藏特性的道具。使用后栏位改为隐藏特性，立即换成当前形态的隐藏特性，并腾出道具栏；之后进化按新形态的隐藏特性。没有隐藏特性的线（鬼斯）不会出现这张卡。它进入守卫奖杯与耿鬼交易的候选池（`add-route-branches`）。
- **"必中"的翻译**：本作是自动瞄准，没有命中率，"必中"类效果改成在这里有实际意义的效果：
  - **无防守**：本线招式没有前摇，范围 +15%；代价是自身受到的伤害 +15%。正作里无防守的双方都必中，所以代价也作用在自己身上。
  - **沙隐**：沙暴中受到的攻击有 20% 概率无效。正作里沙隐提高闪避。
  - **浮游**：不受地面类场地伤害（孢子、毒池、地面落点）影响。
  - **避雷针**：吸引附近的电系弹道，并提高特攻。
- 特性数值仍按阶段给出，`stats.ts` 改为读当前形态在 `player.abilitySlot` 上的特性。

### 3. 天气构筑

- **新招式**，原型为 `weather`（新增 `archetypes/weather.ts`）：施放后把 `world.weather` 设成对应天气，持续 30 秒，冷却 40 秒。同一时刻只有一种天气，后施放的覆盖先施放的，和正作一样。合作中由房主结算。

| 招式               | 天气   | 加入哪些线的 kit |
| ------------------ | ------ | ---------------- |
| 大晴天 `sunny-day` | 大晴天 | 小火龙、妙蛙种子 |
| 求雨 `rain-dance`  | 下雨   | 杰尼龟、皮卡丘   |
| 沙暴 `sandstorm`   | 沙暴   | 小拳石           |

冰雹没有冰系线，暂时只作为 `add-field-events` 的野外天气出现。

- **延长天气的道具**：正作的天气岩石让己方施放的天气持续时间 ×1.6。
  - 炽热岩石 `heat-rock`、潮湿岩石 `damp-rock`：新增。
  - 沙沙岩石 `smooth-rock`：已有，保留原效果，另加延长沙暴。
- **天气中的招式**：只有一张天气表，在 `add-field-events` 的 `content/weather.ts`（下雨时打雷、暴风次数 +1；大晴天时日光束冷却 −40%）。玩家施放的天气与野外天气完全相同，本 change 不另加或叠加招式调整。
- **天气特性**：

| 特性     | 天气   | 效果                                    |
| -------- | ------ | --------------------------------------- |
| 叶绿素   | 大晴天 | 移动速度 +30%，冷却 −15%                |
| 太阳之力 | 大晴天 | 特殊招式伤害 ×1.5，每秒损失 2% 最大生命 |
| 雨盘     | 下雨   | 每秒回复 2% 最大生命                    |
| 沙隐     | 沙暴   | 见第 2 节                               |

悠游自如没有对应的线，不加。

### 4. 誓约组合招式

- **新招式**：`grass-pledge`、`fire-pledge`、`water-pledge`，分别加入妙蛙种子、小火龙、杰尼龟的 kit。原型复用 `smite`，在目标脚下升起柱子。
- **附带状态**：火之誓约施加灼伤，水之誓约施加潮湿，可以接上已有的 steam、shock 反应；草之誓约施加减速。
- **组合**：新增 `content/pledges.ts`：

```ts
export const pledgeCombos = [
  { pair: ["grass-pledge", "fire-pledge"], result: "sea-of-fire" }, // 火海：地面持续灼烧 8 秒
  { pair: ["fire-pledge", "water-pledge"], result: "rainbow" }, // 彩虹：全队附加状态概率 ×2，持续 10 秒
  { pair: ["grass-pledge", "water-pledge"], result: "swamp" }, // 湿地：区域内敌人大幅减速 8 秒
] as const;
```

判定：一个誓约命中点 1.5 秒内、半径 2.5 以内落下另一种誓约，就在两点中点生成组合场，两柱都算参与。组合场是普通的 `Area` 或全队状态，由房主结算。

- **只在合作中触发**：正作里誓约是两只宝可梦配合，而每条线只学自己属性的誓约，单人拿不到第二种。单人中誓约是普通招式，附带状态可以接反应。这是"联机才有"的高光，不改融合规则。
- 融合仍是每人每局一次、本线招牌配方，`fusions.ts` 不变。

### 5. 联机与快照

- 新增的玩家字段 `ability`、交换请求（对方 ID 与剩余时间），以及组合场，都是可序列化数据，`SNAPSHOT_VERSION` 提升一次。
- 交换进化、特性选择、道具使用都按现有个人对话与房主结算规则处理。

## 不做

- **同属性强化道具叠加**：总表里的"道具组合"。正作没有"两件同属性道具"的规则，玩家看不懂，因此不做，保留现有道具等级。
- **冰雹招式与冰冷岩石**：等有冰系线再加。
- **跨线学誓约**：违背正作的学习范围。

## 风险

- 通信线在单人中依赖联系绳。奖杯必出联系绳的保证要用测试保护。还要用模型对照"交换前停留在中间形态"的时间成本。
- 改用正作特性会改变每条线的强度，必须先在模型里对齐，golden 有意变化。
- 天气招式会覆盖野外天气，合作中两人可能互相覆盖。这是正作规则，保留；横幅只提示天气变化一次。
