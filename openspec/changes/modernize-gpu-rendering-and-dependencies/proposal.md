# Proposal

## Why

用户要求升级到发布至少 12 小时的最新稳定依赖，并实际采用上游改进，减少本地 patch、重复资源处理和渲染胶水。当前两端共用 WebGL，但渲染类型、GLSL 注入、UIKit 材质和资源恢复依赖具体后端；只改版本号无法获得完整收益，也无法让未来 WebGPU 与 WebGL 回退快速落地。

## What Changes

- 更新全部直接运行、开发和可选依赖，以及项目声明的运行时与构建工具，覆盖 npm/Bun、PyPI 字体工具和固定的原生资产工具；按统一批次截止时刻核实各自发布时间、稳定标签、peer 约束与 ABI，传递依赖同样遵守 12 小时规则。每批次连同版本、锁文件、补丁和受影响调用方一起迁移并验证，保持精确、可复现。
- 逐项核对五个现有依赖 patch 的行为与上游源码，以已发布的公开能力替换已修复部分；同时删除失去用途的调用、资源保留逻辑和类型扩展。无法替换的最小宿主或字体能力保留明确理由与退出条件，不能把 patch 搬成应用 monkey patch。
- 清理只为开发热更新、模块替换或开发框架重复挂载而存在的兼容代码。开发时允许整页刷新，不保证热更新保留会话；不能以此删除正式环境的卸载取消、正常刷新、上下文恢复或再次开局保障。
- 采用 Three 的 TSL / NodeMaterial 与共享 Renderer 后端模型，迁移世界、VFX、调色、离屏合成、GPU UI 和字体材质；共用效果语义和材质表达，按后端能力选择执行策略，不复制两套业务或美术规则。
- **BREAKING**：调整项目内部 `RenderSurface`、准备屏障和资源生命周期接口，让异步初始化、能力探测、编译成功/失败、单一宿主调度、计时与丢失恢复集中在现有边界；使用上游公开后端组合让宿主独占回退，一次性迁移调用方，不保留旧接口转发。
- 建立可运行的 WebGPU 候选路径及可强制验证的 WebGL2 回退。Web 默认继续走验收后的 WebGL2；本 change 完成后启用 WebGPU 优先策略只需调整入口策略，不需要再次改材质或页面。SDL 继续支持真实原生 GL 呈现，不以 WebView 或假 DOM 代替。
- WebGPU 路径以原生能力设计：GPU 常驻数据、计算与绘制共享缓冲、适用的 GPU 剔除/间接绘制与命令复用、异步管线准备及正确的附件生命周期。至少完成一个正式工作负载的原生 GPU 执行闭环；仅能画出相同画面、逐帧照搬 CPU 更新和上传不算准备完成。WebGL 能力下限不限制 WebGPU 路径。
- 落实适用的 GPU 优化：压缩纹理与官方解码器、准确的附件与 MSAA 生命周期、实例上传和剔除、透明覆盖与阴影开销、节点构建共享与预热、按需绘制与动态分辨率。每项都有采用位置和比较方法，测得无收益或破坏视觉的候选有明确结论，不能以空接口或“以后优化”结项。
- 保留现有视觉、文字质量、动画、危险预警、输入、存档及确定性模拟；以正式页面、长局、恢复循环和真实设备验证更新。GPU 优化不通过降低已确认画质、删效果或重录 golden 达成。

非目标：重做美术或页面、默认开启新光照/后处理风格、把战斗模拟迁到 GPU、替换 SDL 产品宿主、实现通用图形引擎或复制两套业务/美术 shader、保证 dev 热更新连续性；不在本规划阶段修改依赖、源码或资产。

## Capabilities

### New Capabilities

- `dependency-maintenance`：依赖选择的发布时间与稳定性、可复现安装、上游替代本地补丁及剩余扩展的可追溯规则。该工程契约目前散见开发手册和产品约束，现有主规范没有对应边界。

### Modified Capabilities

- `gpu-presentation`：共享呈现允许 Three 的 WebGL2 / WebGPU 后端，要求同一材质语义、视觉等价、可观测性能与完整丢失恢复。
- `platform-services`：宿主负责渲染后端选择、能力报告、有限回退和明确失败，SDL 保持真实窗口与原生 GL 边界。
- `asset-pipeline`：发布压缩资产可在两种后端和 SDL 加载，解码器随发行，按设备能力选择格式且保持缓存身份、来源和质量。

## Impact

- 依赖与工具：`package.json`、`bun.lock`、`bunfig.toml`、`patches/`、字体脚本中的 PyPI/原生工具版本与对应锁定清单、构建/CI/原生打包及 OpenSpec 项目内生成工作流；升级后的 CLI 仍从 `bun run spec` 调用。
- 呈现：`src/platform/{web,native}/render-surface.ts`、`src/rendering/`、`src/prepare/`、`src/run/createRun.ts`、`src/run/view/`、`src/ui/gpu/` 和相应生命周期测试。
- 资产：`src/game/models/`、平台资源服务、`assets/prepare-game-models.py` 之后的发布处理、资源清单与 Web/native 打包。
- 手册：`docs/DEVELOPMENT.md`、`docs/RENDERING.md`、原生手册、状态机地图及引用入口。已有野外事件、训练师演出和共享 UI 验收 change 的业务范围不转移到本 change；实施前以整合后的源码建立对照基线。
