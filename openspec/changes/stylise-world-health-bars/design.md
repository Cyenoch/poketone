# Design

## 决定

- **左上生命组保留。** 它给精确数字、立绘、经验与等级节拍；头顶条是不离开角色的余光读数（护盾、状态、大招）。两者尺度不同，所以都留。头顶条线性，刻度才说真话；HUD 条保留其显示曲线。
- **守卫只用 HUD 条。** 守卫会在半血以下换招（各守卫 `below: 0.5`），HUD 条上画 50% 刻度并加属性徽记；场景里再画一条只会和招式预警抢视线。
- **状态只说一次。** 玩家只会带中毒和减速；它们和助战强化画在玩家条上，身体标记只给敌人。敌人条不带状态点，敌人状态仍由身体标记与染色表达。
- **宝可梦风格、不太占位置。** 浅色云白圆角框 + navy 细外缘，不用硬黑框；尺寸以 CSS 像素钳制（普通 22–44×4、精英 40–72×7、自己 76–104×9、队友 64–88×8；2026-11-18 按玩家反馈放大约一倍，装饰同倍率），按绑定的世界渲染目标换算，远近与设备一致。锚点取这一帧实际画出的身体（敌人跳跃与悬浮、进化中的旧形态）的真实轮廓在当前镜头下屏幕上的最高点再留 8–10px，不压头；玩家轮廓取奔跑、待机动作采样的最大值。普通敌人外缘 70%、空槽半透明，被打的一群不会成为深色地毯。
- **掉血段弹出外框。** 胶囊形，140ms 回弹弹出、350ms 停留、220ms 回落并同时追上，三段同一个计时，后续命中不重启；不足一像素宽的段按宽度淡入，没有硬阈值；弹出幅度按命中占上限的比例放大（25% 封顶），玩家条比敌人条克制，避免自己的条在连续小伤下抖动；quad 留出弹出余量，不裁切、不压徽章。倒地空槽不弹；复活和最大 HP 下降是新基线，不算受击。

## 实现

一个 `InstancedMesh`（四人合作的存活上限 448 再加 64 个余量给死亡淡出的条，另 4 个玩家；超出时精英优先，其次存活敌人，死亡中的条让位）和自定义 `ShaderMaterial`：顶点着色器按 `projectionMatrix` 和视口算出每世界单位的 CSS 像素，宽度跟随体型并钳制，条中心对齐设备像素；片元着色器按画家顺序合成外框、轨道、填充、护盾、掉血段、刻度、徽章（3×5 像素数字，无字形图集）、状态点与大招星。`depthTest` 关闭，`renderOrder` 80：在招式特效与本机脚环（60+）之上、救援光柱（900）之下；实例顺序为敌人、队友、自己。视图只读 sim 状态，不调用有副作用的 sim API。

- **敌群不铺满屏。** 普通敌人的条只在最后一次受伤后约 2.6s 内显示（末 0.4s 淡出），下次受伤 0.12s 淡入；隐藏的条仍按实体追踪，掉血段不会从满血重来。精英常显。玩家条加一圈 3px 柔和阴影并最后绘制，压在敌人条上仍可辨。倒地的条只剩空槽，不带状态点、大招星或金框。
