## 数据

`run.stats()` 返回 `PlayerSheet`：属性拆解 `sheet`，以及打开瞬间的 `time`、`kills`、`stardust`、`moves[{id, level, damage}]`、`items[{id, level}]`。招式伤害取 `MoveState.damage`（combat.ts 结算时累计，按招式记；终极技与同伴伤害不计入招式）。面板是打开时的快照，与现有属性页一致；联机中世界继续运行，重新打开即刷新。

每秒伤害 = 招式累计伤害 ÷ 本局用时（用时为 0 时显示 0）。占比 = 该招式 ÷ 全部招式伤害。道具效果文字复用图鉴的 `itemEffect(id, level)`，与卡面/图鉴同一措辞。

## 布局

框架、标题区（头像、名字、属性、等级、特性）、关闭键沿用现有属性窗。标题区下方一条 Tab 栏（与图鉴相同的黄色选中、白描边规则），下方是当前页。

「战况」：顶部一行四到五个数字块（大号数字 + 小标签）；下方两栏：左「招式」行（图标、名称、属性标签、Lv、累计伤害，以及按招式属性着色的占比条、占比与每秒伤害），右「道具」行（图标、名称、Lv 当前/上限、效果文字）。短横屏缩小字号与间距，仍两栏并在框内滚动。没有道具时右栏只显示空态一句。

「属性」：现有三组属性行与悬停明细原样保留。

## 输入

两页的控件都在同一控件表里，隐藏页的控件 `enabled()` 为 false，方向键/手柄只在当前页移动。PageUp/PageDown（LB/RB）在面板打开时切页而不是滚动；点 Tab 也切页。触屏：HUD 右上角暂停键旁的面板按钮。C 仍可开关。

## 不做

- DuckDB：数据量小、内容表已是类型化 TS，Web 端要额外数 MB WASM 和原生库；分析需求以后用导出 CSV 由 duckdb CLI 读取即可。
- 实时刷新、伤害随时间曲线、同伴与终极技伤害统计。
