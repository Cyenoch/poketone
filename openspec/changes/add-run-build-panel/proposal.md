## Why

局内只有一张“属性”拆解窗，且要从暂停菜单进入。玩家看不到招式各自打了多少伤害、道具当前等级的实际效果和本局战况，构筑判断只能靠记忆。暂停菜单里的入口在联机中还会让人误以为打开它会暂停。

## What Changes

- 局内面板改为两页：「战况」（本局用时、击败数、招式伤害、每秒伤害、星星沙子；每个招式的等级、累计伤害、占比与每秒伤害；每件道具的等级与当前等级效果）和「属性」（保留现有属性分组、来源条与明细）。
- 打开时默认「战况」；PageUp/PageDown 与手柄 LB/RB 切页，Tab 栏可点按。
- 入口：键盘 C、手柄 LB，以及 HUD 右上角新增的面板按钮（触屏入口）。删除暂停菜单里的「属性」按钮。
- 不新增存档字段、联机协议字段或 DuckDB 等数据设施；数据来自本端已有的玩家状态。

## Impact

- `src/ui/gpu/run-overlays-stats-panel.ts`、新增战况页模块、`run-overlays.ts`（暂停菜单、切页）、`run-hud.ts`（按钮）。
- `src/run/createRun.ts` 的 `stats()` 返回面板所需的玩家数据；`src/run/session.ts` 去掉菜单来源。
- `scripts/qa/lib/screens.mjs` 改为从按键打开面板。
