## ADDED Requirements

### Requirement: 局内构筑面板

局内 SHALL 提供构筑面板，分「战况」与「属性」两页。「战况」SHALL 显示本局用时、击败数、招式伤害合计与每秒伤害、星星沙子，每个招式的等级、累计伤害、占比与每秒伤害，以及每件道具的等级和当前等级效果；「属性」SHALL 显示属性分组及其来源明细。面板 SHALL 可由键盘、手柄和触屏打开、切页与关闭，且 MUST NOT 从暂停菜单进入。

#### Scenario: 查看招式贡献

- **WHEN** 玩家在局内打开构筑面板
- **THEN** 默认显示「战况」，每个招式按累计伤害列出，并显示其占全部招式伤害的比例和每秒伤害

#### Scenario: 触屏打开

- **WHEN** 触屏玩家点按 HUD 右上角的面板按钮
- **THEN** 打开构筑面板；点按 Tab 切换页面，关闭键返回游戏

#### Scenario: 手柄切页

- **WHEN** 手柄玩家按 LB 打开面板后按 RB 或 LB
- **THEN** 在「战况」与「属性」之间切换，方向键只在当前页的控件间移动

#### Scenario: 暂停菜单

- **WHEN** 玩家打开暂停菜单
- **THEN** 菜单中没有打开构筑面板的按钮
