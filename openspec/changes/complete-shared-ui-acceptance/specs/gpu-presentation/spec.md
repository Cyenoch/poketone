## ADDED Requirements

### Requirement: 共享界面完成证据

全量共享 UI 迁移的完成声明 SHALL 附正式页面视觉/动态对照、代表尺寸与缩放、Web/native 生命周期和真实输入设备的验收记录；每份记录 MUST 标明被测构建和未覆盖范围。

#### Scenario: 仍只有合成手柄事件

- **WHEN** 页面注入事件通过但真实手柄未验证
- **THEN** 仅记录合成输入通过，真实手柄任务保持未完成，不宣称所有设备验收通过

#### Scenario: 旧版本已有用户验收

- **WHEN** 旧版本已获用户确认而当前版本仍有后续界面/宿主改动
- **THEN** 保留旧确认的批次范围，为实际变化补证据，不把旧确认外推到全部当前行为
