# Design

## Context

读取主规范与DESIGN。旧迁移/停工文档已清理；历史通过不外推到当前整树。

当前为单画布共享宿主；旧交接的双 canvas 和停工草稿状态是历史。测试采用当前正式 App，不以隔离 UIKit 页面代替。

## Goals / Non-Goals

目标是关闭 UI/宿主迁移的真实验收缺口，区分代码接线、浏览器视口、真实设备和用户验收。

非目标是再次重做大厅、Toast 或所有历史矩阵；不增加 reduced-motion，不迁移存档，不做完整玩法平衡或发行工程。

## Decisions

- 建立“页面/路径 → 被测构建 → 证据 → 尚缺范围”的一次验收记录。已有同机制证据可引用，不为了清单好看重复跑。
- 代表尺寸使用桌面 1280×800、手机 844×390，包含实际发生风险的小横屏和缩放边界；全文字墨迹、滚动、焦点和必要操作需看正式截图与动态。
- Web context loss/restore 与 native context 重建按各自正式生命周期验证，不把 Web context 身份要求套到 SDL 重建。
- 合成输入与物理设备分栏，实际设备不可用的任务保持未勾选，不能用注入事件代替。

## Risks / Trade-offs

迁移前截图可能只存在临时目录。若原基准不可恢复，记录具体缺失及可用的已确认基准，不伪造像素/动态保真通过。手柄和手机需实际设备条件；此次文档接入没有提供该证据。

## 沿用的基准与例外

- 2026-11-06用户将逐像素一致转为保持视觉质量、布局、节奏与交互。截图与动态对照仍必要，不设逐像素门禁。
- 旧暂停DOM截图 `<local-browser-artifacts>` 和同批 `pre-starter-1280x800.png` 只对应旧页面。原交接中的外部临时基准须先确认存在和适用版本，不能当当前大厅稿。
- 放逐禁用卡接受卡面50%与上层80%的组透明近似，来源为2026-11-06迁移记录。保留此视觉例外，不自动新增离屏合成工作。
- 字体质量优先于首屏参考时限；基础字符范围与SC地区字形仍属暂定，Latin Extended-A合并其他字体需视觉确认。字集来源查字体SOURCES；本change核对用户决定与真机小字，不从manifest存在反推批准。

## 仍需的代表检查

验收按实际缺口选真实Xbox/DualSense/Switch、USB/Bluetooth、浏览器/SDL，覆盖轴端点、拔插、失焦、文本/系统权限和认领。设置范围遵循 [进度规范](../../specs/progress-save/spec.md)；政策对齐不替代物理设备输入验收。页面包括满背包/档案库、锁定详情、准备好的融合、深层图鉴返回、真正结算后重开及host/guest；合成输入不能代替这些设备证据。

守卫全图拾取卡顿的原设备复测沿用2026-11-08数值与拾取检查。Chrome/Metal受控长局及两次进化边界未复现数秒阻塞；进化后约1.5秒选卡等待已有持续绘制证据。此结果不关闭用户原始报告，不以推测性的缓存优化或缩短演出来冒充性能修复。

塔第七层约每3秒卡顿的反馈沿用2026-11-08塔顶性能检查。本机受控场景未复现周期长帧；普通受伤全局减速的移除属于独立反馈调整。原设备、单人/联机模式与自然成长构筑尚待核对，本项继续保持未完成。
