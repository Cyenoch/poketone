# Proposal

## Why

用户已完成三名原创训练师的角色探索，现要求大厅选择训练师，并用该角色承接开局「就决定是你了，XXX！」投球释放、局内短会话和终极技切入。训练师当前只决定立绘、对白和演出，后续加成与主动技能不属于本次范围。

## What Changes

- 将澄汐、朔野、夜苇与新增夏晴按角色整理独立目录，采用已确认的年轻夏装方向，保留设定、原始多视图、生成提示词、固定画风参考与发布资源来源。
- 大厅增加训练师选择，沿用本机大厅偏好；前三人默认可用，夏晴按本机累计击败 5,000 只解锁，未解锁显示剪影与进度，可预览但不改变出发身份。同角色可重复用于多人席位。
- 新局在战斗开始前展示训练师切入、伙伴名称、抛球弧线与精灵球打开释放；换区与重连不重播开局。
- 局内根据真实事件及间隔出现短对白；终极技按实际施放事件显示角色装饰切入。保持移动和战斗可操作，重要告警优先。
- 多人携带每席位的训练师身份，开局准备屏障涵盖释放演出；本机与队友演出区分，避免重复、遮挡叠加和过期补播。
- **BREAKING**：房间协议增加必填训练师身份并提升协议版本，混用旧版本明确拒绝。

## Capabilities

### New Capabilities

无；沿用现有呈现、多人和资产能力边界。

### Modified Capabilities

- `gpu-presentation`：大厅选择训练师、开局释放与战斗中人物切入的呈现及交互。
- `multiplayer`：训练师身份归属、多人开局准备、演出并发与恢复。
- `asset-pipeline`：按训练师归档源图与派生立绘，提示词和画风参考可复用。
- `progress-save`：用已有累计击败数派生训练师解锁，保持本机保存与导入一致。

## Impact

涉及 `src/lobbyPick.ts`、共享大厅/房间/HUD、`src/app/session.ts`、`src/run/session.ts`、`src/run/createRun.ts`、运行画面、房间协议与 Harbor；原始训练师素材和发布图片进入现有图像准备与内容哈希管线。不增加依赖，不引入训练师战斗字段、加成、主动技能或衣橱系统。旧产品入口中「没有训练师」的描述按此次明确需求更新，玩家仍直接操控宝可梦。
