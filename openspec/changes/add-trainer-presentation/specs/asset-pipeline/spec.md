# Spec Delta

## ADDED Requirements

### Requirement: 训练师素材归档与画风复用

训练师源素材 SHALL 按角色保存在独立目录，表情、立绘及后续派生素材归入对应角色。生成素材 SHALL 保留完整提示词或可无损还原的组成、实际模型、可用参数与图像参考；共享画风 SHALL 指向固定原始参考。发布图像 SHALL 可追溯至角色源文件及处理步骤。

#### Scenario: 新增角色或表情

- **WHEN** 制作新的训练师或已有训练师的新表情
- **THEN** 可从现有记录复用画风与对应角色参考，保存新增生成记录，不覆盖原始多视图及修正前来源
