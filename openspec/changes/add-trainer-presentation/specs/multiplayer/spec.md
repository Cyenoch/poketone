# Spec Delta

## ADDED Requirements

### Requirement: 每席位训练师身份

合作 SHALL 使用各玩家在大厅选定的训练师，房间显示该身份，允许多人选择相同角色。身份 SHALL 在开局配置中固定并随原席位重返保留；未知身份或不兼容协议 MUST 在加入前明确拒绝，不替换为其他角色。

#### Scenario: 四人选择不同或重复角色

- **WHEN** 四个席位带着各自训练师进入房间并出发
- **THEN** 各端的席位、训练师与伙伴对应一致，同角色仍以玩家标签区分

#### Scenario: 修改本机偏好后重返

- **WHEN** 客机断线后更改大厅训练师再重返原对局
- **THEN** 该对局仍使用原席位开局时的训练师，不重新投球，不改变其他玩家身份

### Requirement: 多人释放与演出归属

合作开局 SHALL 等在线席位完成资源准备与释放演出后开始共享战斗；离线席位不无限阻塞，失败保持显式。战斗演出 SHALL 复用已有可靠事件及其发生时间，不增加可改变战斗的演出指令；本机施放优先呈现，队友短提示标明席位，重传和过期事件不得重复或延迟补播。

#### Scenario: 载入较慢的客机

- **WHEN** 一名在线客机仍在准备或播放开局释放
- **THEN** 队伍保持开局等待，客机不会在不可操作的演出中受到战斗伤害

#### Scenario: 多人同时施放

- **WHEN** 多名玩家同刻施放终极技
- **THEN** 各端优先显示自己的切入，队友演出不叠满屏幕、不冒充本人，世界效果与技能结算照常发生
