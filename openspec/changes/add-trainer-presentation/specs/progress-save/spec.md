# Spec Delta

## ADDED Requirements

### Requirement: 训练师解锁使用累计击败记录

澄汐、朔野与夜苇 SHALL 默认可用；夏晴 SHALL 在本机已入账累计击败数达到 5,000 时自动解锁，不消费星星沙子，不增加独立解锁存档字段。胜利、失败与主动结束对局的计数 SHALL 沿用现有结算规则。重载、存档导入与记录重置后 SHALL 从当前进度重新推导可用性，已选但变为锁定的训练师回到默认可用角色。

#### Scenario: 跨过门槛

- **WHEN** 玩家已有 4,999 击败记录，并在一次结算中取得至少 1 次新的击败
- **THEN** 成功入账后夏晴可用，刷新仍保持解锁，不额外消耗货币

#### Scenario: 导入未达标存档

- **WHEN** 玩家曾选夏晴，随后导入累计击败不足 5,000 的有效存档
- **THEN** 夏晴恢复锁定剪影，实际选择校正为默认训练师，不能由旧偏好绕过门槛
