# Spec Delta

## ADDED Requirements

### Requirement: 联机独立页面

联机 SHALL 是经共享幕布进出的独立页面，而不是大厅上的弹窗；同一页面覆盖创建/加入/重返入口、房间码输入、一至四人房间、等待房主、出发中和错误状态。页面 SHALL 提供本人训练师与已解锁伙伴选择，房主另有任务选择；键鼠、触控和手柄均可操作，桌面与手机横屏不溢出安全区。离开页面时未交给对局的连接 SHALL 关闭。

#### Scenario: 从大厅进入联机

- **WHEN** 玩家在大厅选择联机
- **THEN** 幕布以「联机」标题切到联机页面，返回时幕布回到大厅且房间连接关闭

#### Scenario: 联机局再来一局

- **WHEN** 联机对局结束后玩家选择再来一局
- **THEN** 幕布直接回到联机页面入口，不先停留在大厅
