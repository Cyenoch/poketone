# Design

## 定位

宝可梦打，训练师帮。训练师的一切效果都是“支援”：回复、解除异常、短时强化、信息。训练师 MUST NOT 直接造成伤害，也不提供与终极技重叠的爆发清屏。

## 对现有设计的直接评价

- 训练师现在是纯装饰，`trainers.ts` 明说不影响战斗；加入效果后它要进入开局配置、模拟、快照、联机和种子码，改动面不小，但没有绕开的办法。
- 夏晴靠 5,000 击败解锁。如果训练师有效果，解锁就变成“变强”。所以四人的效果必须是同级别的不同选择（侧向选择），不能有明显最强。
- 被动如果是“攻击 +10%”这类数值，会和研究所、道具、羁绊叠在一起，而且会让大家都选同一个人。所以被动优先做成和角色身份对应的玩法差异（信息、站点经济、同伴、收集），数值类只用于同伴。
- 多一个按钮是实际成本：手机横屏右侧已有冲刺、终极技、交互。训练师道具的按钮小一号，放在终极技旁边，冷却中变灰；左下角保持空着（拇指区）。

## 磨合度 / 羁绊

用户提到“磨合度 / 羁绊之类的设计”。大版本里已有 `add-partner-bond`：每只伙伴一份羁绊，5 级，奖励来自正作亲密度效果（挺住、自己治好）和异色外观。

不另做“训练师 × 宝可梦”的磨合度，原因：

- 4 位训练师 × 每只伙伴分别积累，进度被切成很多份，玩家换训练师就像“重新开始”，会惩罚尝试。
- 两套成长叠在一起，效果来源说不清，平衡也更难。

改为用对白建立联系：训练师的局内对白分三档（羁绊 1–2、3–4、5），羁绊越高越亲近。不增加数值，只用已有的羁绊等级。若以后要给组合加效果，再单独提案。

## 数据

```ts
// sim/content/trainers.ts（模拟可读，不含立绘和对白）
export const trainerKits = {
  chengxi: { assist: "xSpeed", passive: "scout" },
  shuoye: { assist: "superPotion", passive: "tinker" },
  yewei: { assist: "direHit", passive: "naturalist" },
  xiaqing: { assist: "fullHeal", passive: "caretaker" },
} as const;
```

- 数值放 `content/params/trainers.ts`：冷却 90 秒；作用半径与 `coop` 的救援半径同量级；速度强化 8 秒（移动 +20%、攻击速度 +15%）；好伤药回复 25% 最大生命；要害攻击 6 秒必定要害；万灵药解除全部异常并免疫 4 秒。具体值以模型为准。
- 被动：
  - `scout`：交互点、出口、奖励标记的小地图显示距离加大（只影响画面读取的距离阈值，模拟里只是一个数值）。
  - `tinker`：催眠貘遗忘返还的宝可梦币 +50%（催眠貘本来就不限次数，比尔的机器受“每局一次融合”约束，不加次数）。
  - `naturalist`：异色出现率 ×1.5（异色判定是全队共享的，队伍里有一人选夜苇即生效，不叠加）；结算时自己写入的遇见计数 +50%（`redesign-lab`）。
  - `caretaker`：本局同伴伤害 +15%、攻击间隔 −10%（同伴不会被攻击，没有生命）。
- `src/trainers.ts` 保留名字、颜色、对白和立绘；对白按羁绊分档后改为 `lines: { low; mid; high }`。

## 模拟

- `RunConfig.players[].trainer` 必填；本地单人从大厅偏好写入，联机沿用房间里每席的训练师。
- `Player.trainer`、`Player.assistReady`（下次可用的世界时刻）。世界快照版本加一。
- `assist` 指令：存活且冷却完成时生效，否则忽略。开局冷却为 0（第一次可以立刻用）。
- 结算在共享世界里，效果写入 `Player` 的短时状态（复用现有的计时增益结构），由 `stats.ts` 读取。
- 事件：`{ t: "assist", player, item }`，画面据此播放投掷、生效与训练师切入（复用 `trainer-cutin` 的短切入，不打断操作）。

## 联机

- 每位玩家只能用自己的训练师道具；作用于半径内的所有存活队友。
- 自己发出的指令按现有“各端拥有自己玩家动作”的规则提交，房主结算共享效果。

## 种子码

- 训练师效果是侧向选择，不影响“同一局”的公平比较；成绩条目记录训练师，便于朋友对照。

## 不做

- 不做训练师升级、装备或衣橱。
- 不做训练师直接攻击或捕捉。
- 不做训练师 × 宝可梦的磨合度数值。
