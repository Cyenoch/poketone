# Proposal

## Why

用户在 2026-11-17 要求整套游戏 UI 换新：以一张斜切二次元菜单为风格参考（只借风格不照搬版式），同时更有宝可梦元素，并与训练师选择/演出统一设计。现有海岸蓝/暖黄指令窗与海岸大厅不再是确认方向。

## What Changes

- 新视觉语言：ink / paper / 精灵球红主操作；全局唯一斜角 −14°（文字正立）；圆角 6、硬投影；精灵球、属性纹章、属性卡面纹理与球云底纹作为宝可梦元素。不加编号、英文副名等现有系统没有的元素。
- 大厅重做：左半选训练师（属性色斜切大色块 + 全身立绘），右半选宝可梦（线条精灵球舞台 + 伙伴 GLB + 名牌/属性/最佳记录/进化链/精灵球徽章列表/背包），右下路线、难度与出发，顶部斜切页签。
- 共享控件重做：斜切页签、主/次按钮、分段选择、精灵球徽章、箭头、名牌展开；动效采用 EASE/SNAP 曲线与入场编排；页面过渡改为三层斜切幕布。
- 图鉴、研究所、联机、设置/存档弹窗、Toast/Tooltip、载入、局内 HUD、选卡、暂停、结算、站点逐屏换用新语言；行为与操作契约不变。
- 训练师大厅全身立绘（新增素材，保留生成记录）。

## Capabilities

### New Capabilities

无。

### Modified Capabilities

- `gpu-presentation`：「共享 GPU 界面」改为以 2026-11-17 确认的新视觉语言为准；「正常动效保持统一」加入幕布页面过渡与统一曲线。

## Impact

`src/ui/gpu/**`（共享原语、各屏幕、HUD）、`src/app/session.ts` 过场接入、`public/art/trainers/*/lobby.webp` 与源图记录、`DESIGN.md`、`PRODUCT.md`、`.impeccable/surfaces/*`、`docs/README.md`。不改模拟、存档格式与网络协议；golden 不变。训练师选择与演出行为属于 `add-trainer-presentation`，本变更只负责其视觉统一。
