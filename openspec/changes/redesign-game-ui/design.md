# Design

视觉参数最终写入 `DESIGN.md`；本文件记录本次决策与分工。

## 已确认决策（用户 2026-11-17）

- 范围：全部界面，含局内 HUD。
- 主操作色：精灵球红；放弃海岸蓝/暖黄结构色。属性主题色沿用现有 type/theme token。
- 大厅：左训练师、右宝可梦；版式按现有模块，不照搬参考图；舞台为地面线条精灵球（否定了实心红白圆盘）。
- 统一斜角：所有斜切元素 −14°，选中分段同样倾斜，文字正立。
- 训练师大厅立绘为全身；屏幕边缘可裁腿，美术本身不止于腰。
- 不加系统没有的元素（编号、英文副名、招式名、幽灵大数字）。
- 动效参考 vanguard-4wd 的 Three.js `gl-ui`：EASE = cubic-bezier(.2,.9,.25,1)，SNAP = cubic-bezier(.7,0,.2,1)，入场/切换/悬停/主按钮扫光/幕布过场数值见 DESIGN.md「Motion」。
- UI/UX 设计与实现只由 Claude 承担；GPT 至多做审阅。

## 实施顺序

1. 共享原语（token、斜切板、页签/按钮/分段/精灵球徽章、tween、幕布过场、线条球台）。
2. 并行：大厅（含训练师选择）；图鉴 + 研究所；联机 + 设置/存档弹窗 + Toast/Tooltip/载入；局内 HUD + 选卡/暂停/结算/站点；训练师演出（`add-trainer-presentation`）。
3. DESIGN.md / PRODUCT.md / surfaces 简报重写；真实画面验收（1280×800、844×390）；独立审阅。

## 风险

- 共享工作区有多条线程的未提交改动：只做精确编辑，不回滚整文件。
- 空闲循环：新增常驻动效（虚线圈、扫光、底纹）必须走现有 15/30Hz 场景时钟，空闲时不每帧重绘。
- 斜体：GPU 字体无真斜体时不伪造倾斜文字，用字重与斜切底板表达速度感。
