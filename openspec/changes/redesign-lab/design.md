# Design

## 所属版本

大版本「野外与路线」第 4 期。共用约定见 `add-field-events/design.md`「共用约定」。

## 图鉴研究等级

参考阿尔宙斯：每个物种有若干研究任务，每档完成得研究点，满 10 点为研究完成。

- 任务定义在 `sim/content/dex-research.ts`，默认任务按物种的出场方式（普通、只作精英出现、守卫）给出，个别物种可以覆盖：

| 类别 | 遇见                    | 击败                                            | 异色       | 合计 |
| ---- | ----------------------- | ----------------------------------------------- | ---------- | ---- |
| 普通 | 1 / 10 / 50 次，各 1 点 | 1 / 10 / 50 / 150 / 400 只各 1 点，1000 只 2 点 | 1 只，3 点 | 13   |
| 精英 | 1 / 5 次，各 2 点       | 1 / 3 / 10 / 25 只，各 1.5 点                   | 无         | 10   |
| 守卫 | 1 次，4 点              | 1 / 3 / 6 次，各 2 点                           | 无         | 10   |

研究完成只需要 10 点，异色是捷径，不是必需。

精确数值放在 `content/params/research.ts`，按实际出场频率用一局统计校准，目标是大多数普通物种 5 到 10 局完成。

- 计数来自进度 v5 的 `dex`（`add-field-events` 结算写入）。研究等级是 `dex` 的纯函数（`run/research.ts`），不存进度，规则调整后自动按新规则显示。
- 图鉴显示：
  - 未遇见：剪影和「？？？」。
  - 遇见后：名称、模型、属性和出现地图。
  - 研究完成后：数值、招式、掉落，加完成印记。
  - 伙伴形态条目不受影响，照常完整显示。
- 图鉴条目里显示研究任务列表和当前进度，任务行用图标加数字，不写说明句。

## 内容解锁

`sim/content/unlocks.ts`，`UnlockId` 为稳定字符串。每项：

```ts
interface UnlockDef {
  id: UnlockId;
  content:
    | { site: SiteKind }
    | { event: EventId }
    | { marker: MarkerId }
    | { ability: AbilityId }
    | { rule: RuleId };
  // SiteKind / EventId：add-field-events；MarkerId：add-route-branches；AbilityId：deepen-builds（只允许某线的隐藏特性，解析时校验）；RuleId：add-challenge-rules
  requires:
    | { research: EnemyId }
    | { researched: number }
    | { badges: number }
    | { clears: Difficulty };
}
```

- 条件在结算时检查（`recordRun` 之后、保存之前），满足的解锁一次写入 `unlocks`，和其他局外奖励一起只入账一次。
- 解锁不花星星沙子。数值节点继续用星星沙子购买。
- 未解锁内容从对应的内容池过滤掉：交互点和事件的抽取表、出口奖励标记表、隐藏特性的出现资格、挑战规则可选性（`add-challenge-rules` 的 `ruleAvailable`）。
- 第一批解锁清单在实现时从 `add-field-events`、`add-route-branches`、`deepen-builds`、`add-challenge-rules` 的内容表中选出，原则是：
  - 基础内容不锁，新玩家第一局就能见到完整的核心循环。
  - 进阶内容才锁，例如稀有交互点、风险更高的出口标记、隐藏特性、两条高危险度规则（`alpha-elites`、`nuzlocke`）。
  - 物种相关内容由该物种研究完成解锁，例如研究完成鲤鱼王后，钓鱼点可以钓到暴鲤龙。
  - 每项解锁都增加选择或内容，不增加数值。

## 训练师被动

- 夜苇的被动（`add-trainer-support`）让结算时写入的遇见计数 +50%（向下取整，至少 +0）。研究点仍只由进度里的计数推算，不另存加成。

## 合作

- 共享内容池（交互点、事件、出口标记）按房主的 `unlocks` 计算，随 `RunConfig` 下发。
- 个人内容（隐藏特性）按各队员自己的 `unlocks`，写在 `RunConfig.players[]`。
- 遇见与击败计数按 `add-field-events` 的个人规则写入各自进度。

## 研究所场景

由 Claude 按 `DESIGN.md`、`.impeccable/surfaces/src-app-tsx.md` 用 impeccable 设计和实现，新增 `.impeccable/surfaces/src-ui-gpu-lab-ts.md` 简报。

- **场景**：一张风格化实验室背景（Magpie Image，和大厅背景同一画风，记录来源），上面有三个热点：
  - **书架**：研究卷宗，每本卷宗是一个分类，书脊有图标和完成度。卷宗包括图鉴研究（物种网格，按地图分组，点进跳到图鉴条目）、解锁（已解锁和未解锁内容，未解锁显示条件图标）、羁绊（`add-partner-bond` 的节点）。
  - **实验台**：现有数值节点，分组沿用现在的分类，节点画成道具或装置，等级用刻度显示。档案库和背包开关放在实验台的抽屉里。
  - **徽章盒**：8 个徽章位，已获得的显示徽章，未获得的显示门槛得分。
- **导航**：
  - 三处热点是网格导航目标，LB/RB 或 PageUp/PageDown 在三处之间切换，返回键先回场景再回大厅。
  - 触控直接点热点；鼠标悬停时热点高亮。
  - 节点详情只在焦点或悬停时出现，界面上不常驻解释文字。
- **布局**：保留最小布局 760×320，UI 缩放下限 80%，触控目标不小于 44 像素。窄屏（844×390）时场景收为三处的横向条带，内容区占满剩余空间。
- 星星沙子余额继续放在顶行。

## 测试

- 研究等级：给定计数推出的点数和完成状态；精英、守卫、普通三类阈值；完成所需不依赖异色。
- 解锁：条件满足时结算获得一次，重复保存不重复；未解锁内容不出现在抽取结果中（固定种子）。
- 合作：共享内容池按房主解锁，客机未解锁不影响房间内容。
- 图鉴：未遇见物种不泄露名称和数值。
- golden：现有种子在全部解锁的配置下录制，保证原有内容池不变；新增内容在各自 change 里有意重录。

## 不做

- 不删除或改价现有数值节点。
- 不做研究点购买解锁，也不做任何货币购买。
