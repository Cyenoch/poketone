# Proposal

## Why

大版本「野外与路线」（用户 2026-11-17 确认）新增多项局外成长：图鉴研究、异色收藏与外观、道馆徽章、研究所内容解锁、伙伴羁绊、对战塔记录和种子码成绩。它们都要写进本机进度。现行进度是 v4，规范要求旧格式明确拒绝、不迁移；游戏已上线，这条不再适用。

把所有新字段集中在一次格式升级里，各功能 change 只引用这里定义的字段，避免大版本内多次升级格式。

## What Changes

- 进度升到 v5，一次性加入本大版本需要的全部字段（见 design.md）。
- 游戏已正式上线（用户 2026-11-17 确认），进度与导出格式从此需要数据迁移：读到 v4 时保留全部旧数据并升级为 v5（新字段为空），升级结果保存成功前不覆盖原记录。以后每次进度格式升级都带上从上一版的升级。
- 项目约定「不做存档迁移」改为只约束世界快照和设置字段；`CLAUDE.md` 与 `docs/` 同步改写。
- 存档导出格式随进度升级。世界快照版本由各功能 change 在新增世界字段时提升，快照不跨版本兼容（只用于对局内恢复和联机，不长期保存）。

## Capabilities

### Modified Capabilities

- `progress-save`：「仅接受当前存档格式」改为「已发布存档逐版升级」。
